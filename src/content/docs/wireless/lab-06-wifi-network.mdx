## أهداف الجلسة

- تعرف المصطلحات الأساسية: نقطة الوصول، و SSID، و BSS، و ESS.
- تعرف أنواع الحماية، وليش WPA2 و WPA3 أحسن من WEP والشبكة المفتوحة.
- تعرف مراحل اتصال الموبايل بالشبكة.
- تشوف الشبكات حواليك ومواصفاتها على جهازك.

## ملخص نظري

### معيار الواي فاي: IEEE 802.11

<Concept term="الواي فاي" en="Wi-Fi">

شبكة محلية **لاسلكية**: بتوصل الأجهزة ببعض بموجات راديو بدل الكابلات. القواعد تبعها كتبتها منظمة المهندسين **IEEE**، فكل الأجهزة من كل الشركات بتفهم على بعض.

**وين موجود؟** بالبيوت، والمقاهي، والجامعة، وحتى بالطابعات والتلفزيونات.

</Concept>

الواي فاي اسمه الرسمي **IEEE 802.11**، وإله أجيال كتير:

| الجيل | التردد | أعلى سرعة تقريباً |
| --- | --- | --- |
| 802.11b | 2.4 GHz | 11 Mbps |
| 802.11a | 5 GHz | 54 Mbps |
| 802.11g | 2.4 GHz | 54 Mbps |
| 802.11n (Wi-Fi 4) | 2.4 و 5 GHz | 600 Mbps |
| 802.11ac (Wi-Fi 5) | 5 GHz | أسرع بكتير |
| 802.11ax (Wi-Fi 6) | 2.4 و 5 و 6 GHz | الأسرع حالياً |

### مصطلحات لازم تعرفها

| المصطلح | يعني ببساطة |
| --- | --- |
| **نقطة الوصول (AP)** | الجهاز يلي بيبث الواي فاي (غالباً الراوتر) |
| **محطة (Station)** | أي جهاز موصول بالشبكة: موبايل، لابتوب، طابعة |
| **SSID** | **اسم الشبكة** يلي بتشوفه بقائمة الواي فاي |
| **BSS** | نقطة وصول وحدة والأجهزة يلي حواليها |
| **ESS** | كذا نقطة وصول موصولين ببعض بنفس الاسم (متل الجامعة) |
| **التجوال (Roaming)** | تتنقّل من نقطة وصول لتانية بدون ما ينقطع النت |
| **المصادقة والارتباط** | التعارف مع الراوتر، وبعدين الانضمام للشبكة |

### الحماية

<Concept term="التشفير" en="Encryption">

تحويل الرسالة لكلام مش مفهوم، وبس يلي معه **المفتاح** (كلمة السر) بيقدر يرجّعها. ليش مهم بالواي فاي؟ لأنه الإشارة بالهوا، وأي حدا قريب بيقدر يلتقطها.

</Concept>

| النوع | الحالة | ليش |
| --- | --- | --- |
| **مفتوحة** | ✘ خطر | أي حدا بيتصل، وما في تشفير |
| **WEP** | ✘ ضعيفة | قديمة وبتنكسر بدقايق |
| **WPA2** | ✔ منيحة | الأكثر انتشاراً، وبتشفّر كل شي |
| **WPA3** | ✔ الأفضل | الأحدث والأقوى |

| قيمة Type | نوع الإطار | مثال |
| --- | --- | --- |

## خطوات العملي

### 1. اعمل شبكتك واتصل فيها

<WifiJoinSim />

<Steps>

1. خلي الإعدادات متل ما هي، واكبس **اتصل**. **شو لازم تشوف:** 6 مراحل خضر، والموبايل اتصل.
2. غيّر كلمة السر يلي **بالموبايل** لشي غلط، واتصل. **شو لازم تشوف:** بيوقف عند مرحلة التحقق من كلمة السر.
3. خلي الحماية **مفتوحة**. **شو لازم تشوف:** اتصل بدون كلمة سر، بس في تحذير أحمر.
4. جرّب **WEP**، وجرّب كلمة سر أقل من 8 أحرف مع WPA2. شو بيقلك الراوتر؟

</Steps>

### 2. تجربة حقيقية: شو الشبكات حواليك؟

<Steps>

1. **على لابتوب ويندوز:** افتح **Command Prompt** واكتب:

   ```text
   netsh wlan show networks mode=bssid
   ```

   **على الموبايل:** افتح إعدادات الواي فاي وشوف القائمة (وتطبيق **WiFi Analyzer** بيعطي تفاصيل أكتر).

2. عبّي الجدول لـ 3 أو 4 شبكات:

   | اسم الشبكة (SSID) | الحماية (Authentication) | القناة (Channel) | الحزمة (2.4 أو 5 GHz) | الإشارة (Signal) |
   | --- | --- | --- | --- | --- |
   | | | | | |
   | | | | | |
   | | | | | |

3. لاحظ: هل في شبكة **مفتوحة**؟ وهل في شبكة إلها **أكتر من BSSID** (يعني كذا نقطة وصول بنفس الاسم = ESS)؟

</Steps>

**شو لازم تشوف:** أغلب الشبكات `WPA2-Personal` أو `WPA3`. والشبكات الكبيرة (متل الجامعة) بيطلعلها كذا `BSSID` تحت نفس الـ SSID، وهاد هو الـ ESS.

### 3. مسائل

#### مسألة 1: حجم رأس الإطار

حسب شكل الإطار فوق، احسب:
1. حجم الرأس (كل الحقول قبل Data).
2. أكبر حجم ممكن للإطار كامل.

<details class="answer">
<summary>الحل</summary>

1. الرأس = 2 + 2 + 6 + 6 + 6 + 2 + 6 = **30 byte**
2. أكبر إطار = 30 (رأس) + 2312 (بيانات) + 4 (CRC) = **2346 byte**
</details>

#### مسألة 2: شو نوع الإطار؟

1. إطار حقل Type فيه `00` و Subtype فيه `1000`. شو هو؟
2. إطار حقل Type فيه `10`. شو فيه؟

<details class="answer">
<summary>الحل</summary>

1. `00` يعني إطار **إدارة**، و Subtype `1000` يعني **Beacon**: نقطة الوصول عم تعلن عن حالها.
2. `10` يعني إطار **بيانات**: فيه البيانات نفسها.
</details>

#### مسألة 3: رتّب المراحل

رتّب مراحل اتصال الموبايل: الارتباط (Association)، و Beacon، والمصادقة (Authentication)، و Probe.

<details class="answer">
<summary>الحل</summary>

**Beacon** ثم **Probe** ثم **المصادقة** ثم **الارتباط**. وبعدها التحقق من كلمة السر، وأخذ عنوان IP.
</details>

## النتيجة المتوقعة

- بالمحاكي: الاتصال نجح بكلمة السر الصح، وفشل بالغلط، والشبكة المفتوحة والـ WEP طلعلهن تحذير.
- بالتجربة: جدول فيه 3 أو 4 شبكات حواليك، مع حمايتها وقناتها.
- المسائل: 30 byte للرأس، و 2346 byte لأكبر إطار، و Beacon، والترتيب.

## أخطاء شائعة

| الخطأ | السبب والحل |
| --- | --- |
| `netsh` بيقول ما في واجهة لاسلكية | الجهاز مش فيه واي فاي، أو الواي فاي مطفي. شغّله وجرب. |
| بيطلع شبكة وحدة بس | زيد `mode=bssid` بآخر الأمر، أو حدّث القائمة من إعدادات الواي فاي. |
| خلطت بين SSID و BSSID | SSID **اسم الشبكة**. BSSID **عنوان MAC** لنقطة الوصول. شبكة وحدة ممكن يكون إلها كذا BSSID. |
| فكّرت إنه إخفاء اسم الشبكة بيحميها | لأ، الاسم المخفي بيبيّن بسهولة ببرامج بسيطة. الحماية الحقيقية هي WPA2 أو WPA3 بكلمة سر قوية. |

## الوظيفة

1. ادخل على إعدادات راوتر بيتك (إذا بتقدر)، واكتب: اسم الشبكة، ونوع الحماية، والحزمة، والقناة. وهل في شي لازم يتغير ليصير أأمن؟
2. ليش الجامعة بتحتاج ESS ومش BSS وحدة؟
3. سلّم جدول التجربة 2.

## أسئلة المراجعة

<details class="answer">
<summary>شو الفرق بين SSID و BSS؟</summary>

SSID هو **اسم** الشبكة. BSS هي **مجموعة** نقطة الوصول والأجهزة الموصولة فيها.
</details>

<details class="answer">
<summary>ليش ما لازم نستخدم WEP؟</summary>

لأنها قديمة وتشفيرها ضعيف، وبتنكسر بدقايق. لازم نستخدم WPA2 أو WPA3.
</details>

<details class="answer">
<summary>شو هو إطار Beacon؟</summary>

إطار إدارة بتبعته نقطة الوصول كل شوي لتقول «أنا موجودة، وهاد اسمي ومواصفاتي». منه بتعرف الأجهزة إنه الشبكة موجودة.
</details>
