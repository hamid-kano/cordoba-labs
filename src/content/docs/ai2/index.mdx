## أهداف العملي

بنهاية الجلسات العملية بيكون الطالب قادر على:

1. استخدام **MATLAB** لتمثيل الأنظمة الديناميكية ورسم استجابتها.
2. بناء نموذج نظام تحكم مغلق في **Simulink** ومحاكاته وتحليل نتائجه.
3. تصميم **متحكم عائم (Fuzzy Logic Controller)** من الصفر: المتغيرات، ودوال الانتماء، والقواعد.
4. ربط المتحكم العائم بنموذج Simulink ومقارنته مع متحكم PID تقليدي.

## البرامج المطلوبة

| البرنامج | ملاحظة |
| --- | --- |
| MATLAB (R2021a أو أحدث) | يفضّل R2023a أو أحدث |
| Simulink | |
| Control System Toolbox | للدوال `tf` و `step` و `pidtune` |
| Fuzzy Logic Toolbox | لتصميم المتحكم العائم |

<Aside type="tip" title="ما عندك MATLAB على جهازك؟">
فيك تستخدم **MATLAB Online** من المتصفح عن طريق حساب MathWorks، إذا كان عند الجامعة ترخيص Campus-Wide. وبمختبر الكلية النسخة مثبتة على كل الأجهزة.
</Aside>
