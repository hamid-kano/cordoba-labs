## أهداف الجلسة

- التعامل مع واجهة MATLAB: نافذة الأوامر، ومساحة العمل، والملفات النصية (Scripts).
- إنشاء المصفوفات والمتجهات والعمليات عليها.
- رسم الإشارات باستخدام `plot`.
- تعريف نظام بتابع تحويل `tf` ورسم استجابته للقفزة `step`.

## المتطلبات

- MATLAB مثبت مع **Control System Toolbox**.
- معرفة أساسية بتابع التحويل من مادة نظم التحكم.

## ملخص نظري

**تابع التحويل** هو النسبة بين تحويل لابلاس للخرج وتحويل لابلاس للدخل، بشروط ابتدائية صفرية:

$$
G(s) = \frac{Y(s)}{U(s)}
$$

مثلاً، محرك DC (متحكَّم بالموضع) فيك تقرّبه بالنموذج:

$$
G(s) = \frac{1}{s\,(0.5s + 1)}
$$

رح نستخدم هاد النظام بالجلسات الثلاث الأولى.

## خطوات العملي

### 1. المصفوفات والمتجهات

```matlab
A = [1 2 3; 4 5 6; 7 8 10];   % مصفوفة 3x3
b = [1; 2; 3];                % متجه عمودي
x = A \ b                     % حل جملة المعادلات A*x = b

t = 0:0.01:5;                 % متجه زمن من 0 لـ 5 بخطوة 0.01
size(t)                       % أبعاد المتجه
```

<Aside type="caution" title="انتبه للفرق">
`A*B` ضرب مصفوفات، أما `A.*B` فضرب عنصر بعنصر. نفس الشي بالنسبة لـ `.^` و `./`.
</Aside>

### 2. الرسم

```matlab
t = 0:0.01:5;
y1 = exp(-t) .* sin(2*pi*t);
y2 = exp(-0.5*t);

figure;
plot(t, y1, 'LineWidth', 1.5); hold on;
plot(t, y2, '--', 'LineWidth', 1.5);
grid on;
xlabel('Time (s)'); ylabel('Amplitude');
legend('e^{-t} sin(2\pi t)', 'e^{-0.5t}');
title('My first plot');
```

### 4. تمثيل نظام وتحليل استجابته

```matlab
s = tf('s');
G = 1 / (s*(0.5*s + 1))     % النظام المفتوح

T = feedback(G, 1)          % الحلقة المغلقة بتغذية راجعة واحدية
step(T); grid on;
title('Closed-loop step response');

info = stepinfo(T)          % زمن الصعود، التجاوز الأعظمي، زمن الاستقرار...
```

## النتيجة المتوقعة

- منحني استجابة يوصل للقيمة 1 مع تجاوز تقريبي **4.3%** (لأن ζ ≈ 0.707).
- `stepinfo` بيرجع قيم من الشكل `Overshoot ≈ 4.3` و `SettlingTime` حوالي 4 ثواني.

## أخطاء شائعة

| الخطأ | السبب والحل |
| --- | --- |
| `Undefined function 'tf'` | الـ Control System Toolbox مو مثبت. تأكد بالأمر `ver`. |
| `Matrix dimensions must agree` | استخدمت `*` بدل `.*` بين متجهين. |
| `Undefined function 'saturate'` | الملف مو موجود بالـ Current Folder، أو اسمه مختلف عن اسم الدالة. |

## الوظيفة

1. ارسم استجابة الحلقة المغلقة لما يكون الربح `K = 0.5, 1, 4` (يعني `feedback(K*G, 1)`) على نفس الشكل.
2. اعمل جدول فيه التجاوز وزمن الاستقرار لكل قيمة، واشرح شو تأثير زيادة الربح.
