## ملخص نظري

### شو يعني «نظام»؟

النظام هو أي شي **بيدخله** شي و**بيطلع منه** شي. مثلاً:

| النظام | الدخل | الخرج |
| --- | --- | --- |
| سيارة | دعسة البنزين | السرعة |
| مدفأة | قوة التشغيل | حرارة الغرفة |
| محرك | الجهد الكهربائي | زاوية الدوران |

بـ MATLAB منكتب النظام بشكل كسر اسمه **تابع التحويل**. رح نستخدم بكل المادة هالنظام (متل محرك صغير):

$$
G(s) = \frac{1}{s\,(0.5s + 1)}
$$

ما لازم تفهم الرياضيات تبعه هلق. المهم تعرف إنه بيمثّل «جهاز» منعطيه دخل وبنشوف خرجه.

### كلمتين لازم تحفظهن

- **التجاوز (Overshoot):** قديش الخرج طلع **فوق** القيمة المطلوبة قبل ما يرجع. متل سيارة بدها توقف عند الإشارة، بس بتتجاوزها شوي وبعدين بترجع.
- **زمن الاستقرار (Settling Time):** قديش بياخد وقت لحتى الخرج **يهدا** ويصير قريب كتير من القيمة المطلوبة.

## خطوات العملي

### 1. التعرف على الواجهة

افتح MATLAB، ولاحظ أهم 4 أماكن:

| المكان | شو بيعمل |
| --- | --- |
| **Command Window** | هون بتكتب الأوامر وبتشوف النتيجة |
| **Workspace** | بيبيّن كل المتغيرات يلي عرّفتها |
| **Current Folder** | المجلد يلي عم تشتغل فيه. لازم تكون ملفاتك فيه |
| **Editor** | لكتابة الملفات (Scripts) |

### 2. أوامر بسيطة

اكتب بالـ Command Window سطر سطر، واضغط Enter بعد كل سطر:

```matlab
a = 5
b = 3
c = a + b
d = a * b
```

**شو لازم تشوف:** النتيجة بتطلع تحت كل سطر، والمتغيرات `a` و `b` و `c` و `d` بتظهر بالـ Workspace.

<Aside type="note" title="الفاصلة المنقوطة ;">
إذا كتبت `;` بآخر السطر، MATLAB بينفّذ الأمر بس **ما بيطبع** النتيجة. جرّب: `e = 10;`
</Aside>

### 3. المتجهات (قائمة أرقام)

```matlab
t = 0:1:5          % أرقام من 0 لـ 5، والخطوة 1
t = 0:0.5:5        % أرقام من 0 لـ 5، والخطوة 0.5
```

**شو لازم تشوف:** بالأول `0 1 2 3 4 5`، وبالتاني 11 رقم.

السطر `0:0.5:5` معناه: **ابدأ من 0، وزيد 0.5 بكل مرة، ووقّف عند 5**. رح نستخدمه كتير للزمن.

### 4. أول رسمة

```matlab
t = 0:0.01:5;             % الزمن من 0 لـ 5 ثواني
y = sin(2*pi*t);          % موجة جيبية
plot(t, y)                % ارسم y مقابل t
grid on                   % شبكة لتسهيل القراءة
xlabel('Time (s)')        % اسم المحور الأفقي
ylabel('y')               % اسم المحور العمودي
```

**شو لازم تشوف:** موجة طالعة نازلة، بتعمل 5 دورات كاملة بالـ 5 ثواني.

<Aside type="caution" title="ضرب عنصر بعنصر">
إذا بدك تضرب متجهين ببعض رقم برقم، استخدم `.*` (مع نقطة) مش `*`. مثلاً: `y = t .* t`
</Aside>

### 5. أول ملف (Script)

بدل ما تكتب الأوامر كل مرة، منحطهن بملف:

<Steps>

1. أنشئ مجلد اسمه `AI2-Lab` على سطح المكتب.
2. بـ MATLAB، روح لهالمجلد من **Current Folder** (لازم يكون هو المجلد الحالي).
3. اضغط **New Script** من فوق، رح ينفتح الـ Editor.
4. انسخ كود الخطوة 4 جوّا الملف.
5. احفظ الملف باسم `myfirst.m`.
6. اضغط **Run** (المثلث الأخضر).

</Steps>

**شو لازم تشوف:** نفس الرسمة تبع الخطوة 4.

<Aside type="tip" title="ملفات الجلسات">
بكل جلسة في ملف جاهز للتحميل فوق (بشريط معلومات الجلسة). نزّله، وحطه بمجلد `AI2-Lab`، وافتحه وشغّله. السطور يلي بتبلش بـ `%%` بتقسم الملف لأقسام، وفيك تشغّل كل قسم لحاله بـ **Run Section**.
</Aside>

### 6. تعريف نظام ورسم استجابته

هلق رح نعطي النظام تبعنا «أمر»: **روح للقيمة 1**. ومنشوف كيف بيتصرف.

```matlab
s = tf('s');                  % حرف s خاص بتوابع التحويل
G = 1 / (s*(0.5*s + 1))       % النظام تبعنا

T = feedback(G, 1);           % منربطه بحلقة مغلقة (بيقيس خرجه وبيصحّح)
step(T)                       % بنعطيه أمر "روح لـ 1" ومنرسم الخرج
grid on

stepinfo(T)                   % بيحسب التجاوز وزمن الاستقرار
```

**شو لازم تشوف:** منحني بيطلع لعند 1، بيتجاوزه شوي، وبعدين بيرجع وبيستقر عليه.

## النتيجة المتوقعة

- الرسمة بتوصل لـ 1 وبتتجاوزه **شوي**: التجاوز حوالي **4.3%**.
- بتستقر بعد حوالي **4.2 ثانية**.
- بالـ Workspace لازم يكون عندك `s` و `G` و `T`.

## أخطاء شائعة

| الخطأ | السبب والحل |
| --- | --- |
| `Undefined function 'tf'` | ناقصك **Control System Toolbox**. اكتب `ver` وشوف إذا موجود، أو اطلب من مسؤول المختبر. |
| `Undefined function or variable 'x'` | استخدمت متغير قبل ما تعرّفه، أو كتبت الاسم غلط. MATLAB بيفرّق بين الحرف الكبير والصغير. |
| `Matrix dimensions must agree` | ضربت متجهين بـ `*` بدل `.*`. |
| ضغطت Run وطلع خطأ إنه الملف مو موجود | الملف مو بالـ **Current Folder**. روح للمجلد الصح. |

## الوظيفة

1. غيّر الرسمة بالخطوة 4 لـ `y = sin(2*pi*t) .* exp(-t)`. شو تغيّر؟
2. ارسم استجابة النظام مع ربح مختلف: `T = feedback(4*G, 1)`. سجّل التجاوز وزمن الاستقرار، وقارن مع الربح 1. شو بيصير لما نكبّر الربح؟
