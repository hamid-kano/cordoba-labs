## ملخص نظري

### شو هو المنطق الضبابي؟

<Concept term="المنطق الضبابي" en="Fuzzy Logic">

طريقة تفكير بتشبه تفكير الإنسان: بدل «يا أبيض يا أسود»، بتقبل **الرمادي**. اخترعها العالم **لطفي زاده** سنة 1965.

**ليش منستخدمه؟**
- لما يكون صعب نكتب معادلة للمشكلة، بس سهل نوصف الحل بالكلام.
- منقدر نحط **خبرة الإنسان** جوّا الجهاز على شكل قواعد: «إذا ... فـ ...».

**وين بينستخدم؟** الغسالات (بتقرر كمية المي حسب الوسخ)، والمكيفات، وكاميرات الموبايل، وفرامل السيارات، والقطارات.

</Concept>

### درجة الانتماء

بالمنطق العادي: الشي يا **صح (1)** يا **غلط (0)**.
بالمنطق الضبابي: الشي إله <Term t="درجة انتماء" en="Membership Degree" def="رقم بين 0 و 1 بيقول قديش الشي من مجموعة معينة. 0 يعني أبداً، و 1 يعني تماماً، و 0.6 يعني إلى حد كبير." /> بين 0 و 1.

| الحرارة | بارد | معتدل | حار |
| --- | --- | --- | --- |
| 5° | 1 | 0 | 0 |
| 15° | 0.5 | 0.5 | 0 |
| 20° | 0 | 1 | 0 |
| **24°** | **0** | **0.6** | **0.4** |
| 35° | 0 | 0 | 1 |

يعني 24° هي «معتدلة» بنسبة 60% و«حارة» بنسبة 40%.

### دالة الانتماء

هي **الرسمة** يلي بتعطيك درجة الانتماء لكل قيمة. أشهرها:

- **المثلث** (`trimf`): بيحتاج 3 أرقام: البداية، والقمة، والنهاية.
- **شبه المنحرف** (`trapmf`): بيحتاج 4 أرقام، لأن قمته مسطّحة.

### كيف بيطلع القرار؟ (4 خطوات)

<Concept term="نظام الاستدلال الضبابي" en="Fuzzy Inference System (FIS)">

هو «الصندوق» الكامل: بياخد رقم (متل الحرارة)، وبيمرّقه على القواعد، وبيطلّع قرار (متل سرعة المروحة). بـ MATLAB منسميه `fis` ومنعمله بالأمر `mamfis`. جوّاه 4 مراحل، شوفها بالجدول تحت.

</Concept>

| الخطوة | شو بيصير | بمثالنا (الحرارة 24°) |
| --- | --- | --- |
| 1. <Term t="التضبيب" en="Fuzzification" def="تحويل الرقم العادي (24°) لدرجات انتماء (معتدل 0.6، حار 0.4)." /> | منحسب درجة الانتماء لكل مجموعة | معتدل 0.6، حار 0.4 |
| 2. القواعد | كل قاعدة بتاخد قوة شرطها | «معتدل ← وسط» بقوة 0.6، «حار ← سريع» بقوة 0.4 |
| 3. القص والجمع | كل مجموعة خرج بتنقص على قوة قاعدتها، وبعدين منحطهن فوق بعض | «وسط» مقصوصة على 0.6، و«سريع» على 0.4 |
| 4. <Term t="إزالة التضبيب" en="Defuzzification" def="عكس التضبيب: منرجع من الشكل الضبابي لرقم واحد عادي منقدر نعطيه للمروحة." /> | منلاقي **مركز** الشكل الناتج، وهو الجواب | سرعة حوالي 63% |

<Aside type="note" title="مركز الثقل ببساطة">
تخيّل الشكل الناتج مقصوص من كرتون. **مركز الثقل** هو النقطة يلي إذا حطيت إصبعك تحتها، الكرتونة بتتوازن. MATLAB بيحسبها عنك.
</Aside>

## خطوات العملي

### 1. ارسم دوال الانتماء

```matlab
T = 0:0.1:40;                          % الحرارة من 0 لـ 40
cold = trapmf(T, [0 0 10 20]);         % بارد
warm = trimf(T,  [10 20 30]);          % معتدل
hot  = trapmf(T, [20 30 40 40]);       % حار

plot(T, cold, T, warm, T, hot, 'LineWidth', 2); grid on;
legend('Cold', 'Warm', 'Hot'); xlabel('Temperature'); ylabel('درجة الانتماء');
```

**شو لازم تشوف:** 3 أشكال متداخلة. البارد عالي بالشمال، والحار عالي باليمين، والمعتدل مثلث بالنص.

جرّب تحسب درجة انتماء 24° بإيدك من الرسمة، وبعدين تأكد:

```matlab
trimf(24, [10 20 30])                  % معتدل: لازم يطلع 0.6
trapmf(24, [20 30 40 40])              % حار:   لازم يطلع 0.4
```

### 2. ابنِ نظام المروحة (مدخل واحد)

```matlab
fis = mamfis('Name', 'fan');                       % نظام ضبابي جديد

% المدخل: الحرارة
fis = addInput(fis, [0 40], 'Name', 'temp');
fis = addMF(fis, 'temp', 'trapmf', [0 0 10 20],   'Name', 'Cold');
fis = addMF(fis, 'temp', 'trimf',  [10 20 30],    'Name', 'Warm');
fis = addMF(fis, 'temp', 'trapmf', [20 30 40 40], 'Name', 'Hot');

% الخرج: سرعة المروحة (من 0 لـ 100%)
fis = addOutput(fis, [0 100], 'Name', 'speed');
fis = addMF(fis, 'speed', 'trimf', [0 0 50],     'Name', 'Slow');
fis = addMF(fis, 'speed', 'trimf', [25 50 75],   'Name', 'Medium');
fis = addMF(fis, 'speed', 'trimf', [50 100 100], 'Name', 'Fast');

% القواعد: بالكلام!
rules = [
    "If temp is Cold then speed is Slow"
    "If temp is Warm then speed is Medium"
    "If temp is Hot then speed is Fast"
];
fis = addRule(fis, rules);
```

**شو لازم تشوف:** ما في رسمة. بس بالـ Workspace صار عندك `fis`.

### 3. جرّب النظام

```matlab
evalfis(fis, 24)          % الحرارة 24 درجة
evalfis(fis, 5)           % برد
evalfis(fis, 35)          % حر
```

**شو لازم تشوف:** حوالي **62.9** للـ 24°، وحوالي **16.3** للبرد، وحوالي **83.7** للحر.

### 4. شوف كيف بيشتغل من جوّا

```matlab
ruleview(fis)             % نافذة بتبيّن كل قاعدة وكيف انقصّت
```

<Steps>

1. بالنافذة يلي انفتحت، اكتب `24` بخانة **Input** تحت، واضغط Enter.
2. لاحظ: كل سطر هو قاعدة. شوف وين انقصّت كل مجموعة خرج.
3. بآخر عمود تحت، في الشكل النهائي، والخط الأحمر هو **مركز الثقل** (الجواب).
4. اسحب الخط الأحمر يلي فوق الحرارة يمين وشمال، ولاحظ كيف بيتغير الجواب.

</Steps>

### 5. منحني القرار

```matlab
figure; gensurf(fis); grid on;          % السرعة مقابل الحرارة
```

**شو لازم تشوف:** منحني بيطلع من حوالي 16 (بالبرد) لحوالي 84 (بالحر)، بشكل **ناعم** بدون قفزات.

### 6. زيادة: مدخل تاني (الرطوبة)

هلق منضيف الرطوبة، ومنستخدم **AND** بالقواعد. بالمنطق الضبابي، **AND** معناها: خود **الأصغر** بين الدرجتين.

```matlab
fis = addInput(fis, [0 100], 'Name', 'hum');
fis = addMF(fis, 'hum', 'trapmf', [0 0 30 60],     'Name', 'Low');
fis = addMF(fis, 'hum', 'trapmf', [40 70 100 100], 'Name', 'High');

fis.Rules = [];                                     % منمسح القواعد القديمة
rules = [
    "If temp is Cold then speed is Slow"
    "If temp is Warm and hum is Low then speed is Medium"
    "If temp is Warm and hum is High then speed is Fast"
    "If temp is Hot then speed is Fast"
];
fis = addRule(fis, rules);

evalfis(fis, [24 45])          % حرارة 24، رطوبة 45%
figure; gensurf(fis);          % صار سطح، مش منحني
```

**شو لازم تشوف:** حوالي **63.8**، وسطح ثلاثي الأبعاد.

## النتيجة المتوقعة

| الحرارة | سرعة المروحة |
| --- | --- |
| 5° | ≈ 16.3% |
| 20° | 50% |
| 24° | ≈ 62.9% |
| 35° | ≈ 83.7% |

ومع الرطوبة: `evalfis(fis, [24 45])` بيطلع حوالي **63.8%**.

## أخطاء شائعة

| الخطأ | السبب والحل |
| --- | --- |
| `Undefined function 'mamfis'` | نسخة MATLAB قديمة (قبل 2018b)، أو ناقص Fuzzy Logic Toolbox. |
| خطأ بالقاعدة | الأسماء لازم تطابق **تماماً**: `Warm` غير `warm`. |
| `trapmf` بيعطي خطأ | الأرقام الأربعة لازم تكون **من الأصغر للأكبر**. |
| الخرج طلع 50 دايماً | ولا قاعدة اشتغلت. تأكد إنه القواعد مكتوبة صح، وإنه الدخل ضمن المجال. |
| `ruleview` ما اشتغل | بالنسخ الجديدة استخدم `fuzzyLogicDesigner(fis)`، وبعدين افتح **Rule Inference**. |

<summary>الحرارة 24° معتدلة بدرجة 0.6 وحارة بدرجة 0.4. هل هاد تناقض؟</summary>

</details>

<details class="answer">
<summary>شو يعني AND بالمنطق الضبابي؟</summary>
