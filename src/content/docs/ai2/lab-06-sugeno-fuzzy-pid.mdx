## ملخص نظري

### Mamdani مقابل Sugeno

| | Mamdani | Sugeno |
| --- | --- | --- |
| خرج كل قاعدة | مجموعة عائمة (مثلث مثلاً) | رقم ثابت أو تابع خطي للمدخلات |
| AND الافتراضي بـ MATLAB | `min` | `prod` (الضرب) |
| إزالة التضبيب | مركز الثقل (بيحتاج تكامل عددي) | متوسط موزون: $u = \dfrac{\sum w_i z_i}{\sum w_i}$ |
| السرعة | أبطأ | أسرع بكتير |
| الوضوح | أقرب لتفكير الخبير | أنسب للحساب والتطبيق بالزمن الحقيقي |
| الدالة بـ MATLAB | `mamfis` | `sugfis` |

لما نحوّل متحكمنا لـ Sugeno، كل مجموعة خرج بتصير رقم بمركزها:

$$
\text{NB} = -1,\quad \text{NS} = -0.5,\quad \text{Z} = 0,\quad \text{PS} = 0.5,\quad \text{PB} = 1
$$

### ليش Fuzzy-PD ما بيلغي أثر الاضطراب؟

نظامنا $G(s) = \dfrac{1}{s(0.5s+1)}$ فيه مكامل. لما نضيف اضطراب ثابت $d$ على دخله، لحتى يوقف الخرج عن التغيّر لازم يكون دخل النظام صفر:

$$
u + d = 0 \;\Rightarrow\; u = -d
$$

بمتحكم PD، وبالاستقرار ($\dot e = 0$)، الطريقة الوحيدة ليعطي المتحكم $u = -d$ هي إنه يضل في **خطأ** $e \neq 0$. فبيضل الخرج بعيد عن المطلوب.

### Fuzzy-PID: إضافة تكامل

$$
u = K_u \cdot \text{FIS}\big(K_e\, e,\; K_d\, \dot e\big) + K_i \int e\, dt
$$

الجزء التكاملي بيضل يزيد طول ما في خطأ، لحتى يوصل لـ $-d$ ويرجع الخطأ صفر. بس في مشكلة: أول ما نعطي أمر خطوة، الخطأ بيكون كبير لفترة، فالتكامل بيتراكم وبيعمل **تجاوز كبير**. هي مشكلة **Windup**.

الحل البسيط: **التكامل المشروط**، يعني منكامل بس لما يكون الخطأ صغير:

$$
\frac{dI}{dt} = \begin{cases} e & \lvert e \rvert < b \\ 0 & \text{غير هيك} \end{cases}
$$

```matlab
sug = sugfis('Name', 'fuzzyPD_sugeno');
for v = ["e" "de"]
    sug = addInput(sug, [-1 1], 'Name', v);
    sug = addMF(sug, v, 'trimf', [-2 -1 0], 'Name', 'N');
    sug = addMF(sug, v, 'trimf', [-1  0 1], 'Name', 'Z');
    sug = addMF(sug, v, 'trimf', [ 0  1 2], 'Name', 'P');

sug = addOutput(sug, [-1 1], 'Name', 'u');
sug = addMF(sug, 'u', 'constant', -1,   'Name', 'NB');
sug = addMF(sug, 'u', 'constant', -0.5, 'Name', 'NS');
sug = addMF(sug, 'u', 'constant',  0,   'Name', 'Z');
```

### 2. مقارنة الخرج والسطح والسرعة

```matlab
pts = [0.5 -0.2; 0.3 0.3; 1 1; -0.7 0.2];
[evalfis(mam, pts) evalfis(sug, pts)]

subplot(1,2,1); gensurf(mam); title('Mamdani');
subplot(1,2,2); gensurf(sug); title('Sugeno');

x = 2*rand(1000, 2) - 1;
timeit(@() evalfis(mam, x))
timeit(@() evalfis(sug, x))
```

<Aside type="note" title="شو لاحظت بسطح Sugeno؟">
طلع **مستوي تماماً**: $u = 0.5\,(e + \dot e)$. السبب إنه دوال الانتماء المثلثية المتداخلة مع AND بالضرب والمتوسط الموزون بيعملوا **استيفاء خطي** بين الثوابت، والثوابت نفسها على مستوي. يعني بهالإعداد، Sugeno صار متحكم PD خطي بالضبط! اللاخطية بـ Mamdani جاية من مركز الثقل ومن قص المجموعات.
</Aside>

### 3. استجابة الخطوة للنوعين

حاكي المتحكمين بـ $K_e = 1, K_d = 0.3, K_u = 4$ بدون اضطراب، باستخدام التابع `simFuzzyPID` الموجود بآخر الملف:

```matlab
[t, Ym] = simFuzzyPID(mam, 1, 0.3, 4, 0, 0, 0, 10);

```

معاملات التابع بالترتيب: `fis, Ke, Kd, Ku, Ki, band, d, Tend`. يعني `Ki` ربح التكامل، و `band` حد التكامل المشروط، و `d` قيمة الاضطراب يلي بيبدأ عند `t = 5`.

### 4. الاضطراب: من Fuzzy-PD لـ Fuzzy-PID

منضيف اضطراب $d = 0.5$ على دخل النظام عند $t = 5$، ومنجرب أربع حالات:

```matlab
[t, Y1] = simFuzzyPID(mam, 1, 0.3, 4, 0, 0,   0.5, 20);   % Fuzzy-PD
[~, Y2] = simFuzzyPID(mam, 1, 0.3, 4, 1, Inf, 0.5, 20);   % تكامل دائم
[~, Y3] = simFuzzyPID(mam, 1, 0.3, 4, 1, 0.3, 0.5, 20);   % تكامل مشروط |e| < 0.3
[~, Y4] = simFuzzyPID(mam, 1, 0.3, 4, 1, 0.1, 0.5, 20);   % تكامل مشروط |e| < 0.1
plot(t, [Y1; Y2; Y3; Y4]); grid on; xline(5, ':');
legend('PD', 'PID دائم', 'PID |e|<0.3', 'PID |e|<0.1');
```

### 5. التنفيذ بـ Simulink

<Steps>

1. افتح `lab04_fuzzy.slx` واحفظه باسم `lab06_fuzzy_pid.slx`.

2. **الاضطراب:** ضيف بلوك **Step** (`Step time = 5`، `Final value = 0.5`)، وبلوك **Sum** قبل النظام مباشرة، بحيث يصير دخل النظام $u + d$.

3. **الجزء التكاملي المشروط:** ضيف البلوكات التالية على إشارة الخطأ $e$:

   | البلوك | المكتبة | الإعداد |
   | --- | --- | --- |
   | Abs | Math Operations | |
   | Compare To Constant | Logic and Bit Operations | `Operator = <`، `Constant value = 0.3` |
   | Product | Math Operations | بيضرب $e$ بخرج المقارنة |
   | Integrator | Continuous | `Initial condition = 0` |
   | Gain | Math Operations | `Ki` |

   ```text
   e ──► Abs ──► Compare (< 0.3) ──┐
   e ─────────────────────────────► Product ──► Integrator ──► Gain(Ki) ──┐
   Fuzzy Logic Controller ──► Gain(Ku) ─────────────────────────────────► Sum ──► Saturation(±5) ──► (+d) ──► G(s)
   ```

4. خرج المقارنة نوعه `boolean`. إذا طلع خطأ بالأنواع، ضيف بلوك **Data Type Conversion** لـ `double` قبل الـ Product.

5. عرّف المتغيرات وشغّل:

   ```matlab
   Ke = 1; Kd = 0.3; Ku = 4; Ki = 1;
   fis = readfis('fuzzyPD');
   ```

6. جرّب كمان بلوك Fuzzy من نوع Sugeno: احفظ `sug` بـ `writeFIS(sug, 'fuzzyPD_sugeno')` وحمّله بنفس البلوك.

</Steps>

## النتيجة المتوقعة

**المقارنة بين النوعين:**

| المدخل $(e, \dot e)$ | Mamdani | Sugeno |
| --- | --- | --- |
| $(0.5, -0.2)$ | ≈ 0.119 | 0.15 |
| $(0.3, 0.3)$ | ≈ 0.199 | 0.30 |
| $(1, 1)$ | 0.84 | 1.00 |
| $(-0.7, 0.2)$ | ≈ −0.186 | −0.25 |

- استجابة الخطوة: Mamdani بتجاوز ≈ 0.8% وزمن استقرار ≈ 2.1 s، و Sugeno بتجاوز ≈ 1.4% وزمن استقرار ≈ 1.9 s (أسرع شوي، لأن خرجه أكبر بالمناطق البعيدة عن المركز، متل $(1, 1)$).
- `timeit` بيبيّن إنه Sugeno أسرع بشكل واضح.

**حالات الاضطراب** ($d = 0.5$ عند $t = 5$، و $K_i = 1$):

| الحالة | التجاوز قبل الاضطراب | أعلى قيمة بعد الاضطراب | $y(20)$ |
| --- | --- | --- | --- |
| Fuzzy-PD | ≈ 0.8% | ≈ 1.24 | ≈ 1.21 (خطأ مستقر) |
| PID بتكامل دائم | **≈ 35%** | ≈ 1.21 | 1.00 |
| PID بتكامل مشروط $\lvert e \rvert < 0.3$ | ≈ 5.5% | ≈ 1.21 | 1.00 |
| PID بتكامل مشروط $\lvert e \rvert < 0.1$ | ≈ 1.7% | ≈ 1.23 | ≈ 1.20 (التكامل ما اشتغل!) |

الحالة التالتة هي الأفضل: تجاوز مقبول، وبيرجع الخرج لـ 1 بعد حوالي 4.5 ثانية من الاضطراب.

## أخطاء شائعة

| الخطأ | السبب والحل |
| --- | --- |
| `Undefined function 'sugfis'` | نسختك أقدم من R2018b. استخدم `newfis('name', 'FISType', 'sugeno')`. |
| `addMF` بيرفض `'constant'` | تأكد إنك عم تضيف للخرج بنظام `sugfis` مو `mamfis`. |
| تجاوز كبير كتير بعد ما ضفت التكامل | هي مشكلة Windup. استخدم التكامل المشروط أو صغّر $K_i$. |
| التكامل ما عم يلغي الخطأ | حد التكامل `band` أصغر من الخطأ المستقر يلي بيعمله الاضطراب، فالتكامل ما بيشتغل أبداً. كبّر الحد. |
| `Data type mismatch` بالـ Product | حوّل خرج Compare To Constant لـ `double`. |

## الوظيفة

1. اعمل جدول لـ $K_i \in \{0.5, 1, 2\}$ مع تكامل مشروط $\lvert e \rvert < 0.3$: التجاوز، والذروة بعد الاضطراب، والزمن لحتى يرجع الخرج ضمن 2% من 1.
2. حوّل الخرج بـ Sugeno لتابع خطي (`'linear'`) بدل الثوابت، مثلاً للقاعدة Z/Z: $u = 0.2e + 0.1\dot e$. شو تأثيره على السطح؟
3. نفّذ المتحكم بـ Simulink وتأكد إنه النتائج بتطابق الكود.
4. سلّم `.m` و `.slx` وتقرير فيه المنحنيات وجدول الوظيفة الأولى.

## أسئلة المراجعة

<details class="answer">
<summary>إذا كان Sugeno هون صار PD خطي، ليش منستخدمه أصلاً؟</summary>

لأنه هالشي صحيح بس بهالإعداد البسيط (ثوابت على مستوي، ومثلثات متداخلة بانتظام). أول ما نغيّر الثوابت (مثلاً نخلي PB = 1.5 أو Z بقيمة غير صفر بمنطقة معينة)، أو نستخدم توابع خطية مختلفة لكل قاعدة، أو دوال انتماء غير منتظمة، بيصير السطح غير خطي. ميزة Sugeno إنه سريع، وخرجه سهل نحسبه ونحلله رياضياً.
</details>

<details class="answer">
<summary>ليش الخطأ المستقر مع Fuzzy-PD كان حوالي 0.21 بالضبط؟</summary>

لازم $K_u \cdot \text{FIS}(K_e e, 0) = -0.5$، يعني $\text{FIS}(e, 0) = -0.125$. سطح Mamdani حول المركز ميله تقريباً 0.58، فـ $e \approx -0.125 / 0.58 \approx -0.21$، يعني الخرج بيستقر عند $1.21$ تقريباً.
</details>

<details class="answer">
<summary>ليش التكامل الدائم عمل تجاوز 35% مع إنه $K_i$ صغير؟</summary>

لأنه بأول ثانية الخطأ قريب من 1، فالتكامل بيتراكم بسرعة. لما يوصل الخرج للقيمة المطلوبة، التكامل بيكون مخزّن قيمة كبيرة، فبيكمّل يدفش الخرج لفوق. ولأن النظام فيه مكامل أصلاً، صار عنا مكاملين بالحلقة، وهاد بيخلّي النظام أقرب لعدم الاستقرار.
</details>

<details class="answer">
<summary>كيف منختار حد التكامل المشروط <code>band</code>؟</summary>

لازم يكون **أكبر** من الخطأ المستقر يلي ممكن يعمله أكبر اضطراب متوقع (هون 0.21)، وإلا التكامل ما بيشتغل. وبنفس الوقت **أصغر** من الأخطاء الكبيرة يلي بتصير وقت تغيير المرجع، لحتى ما يصير Windup. بمثالنا 0.3 حل وسط منيح.
</details>
