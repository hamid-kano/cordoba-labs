**الجزء الأول:** في نوعين من المتحكمات الضبابية. **Mamdani** (يلي استخدمناه) خرج كل قاعدة فيه **شكل** (مثلث). **Sugeno** خرج كل قاعدة فيه **رقم واحد**، فهو أبسط وأسرع.

**الجزء التاني:** تخيّل سيارة على **طلعة**. إذا ضليت دايس نفس الدعسة، السيارة رح تبطّئ. لازم **تزيد شوي شوي** لحتى ترجع لسرعتك. هاي الزيادة شوي شوي اسمها **التكامل**.
</Aside>

## ملخص نظري

### Mamdani و Sugeno

النوعين بأسماء العلماء يلي اقترحوهن: <Term t="Mamdani" def="إبراهيم ممداني، عمل بلندن أول متحكم ضبابي حقيقي سنة 1975 لمحرك بخاري." /> و<Term t="Sugeno" def="تاكاجي وسوجينو، عالمين يابانيين اقترحوا سنة 1985 إنه خرج القاعدة يكون رقم بدل شكل، فصار الحساب أسرع." />.

| | Mamdani | Sugeno |
| --- | --- | --- |
| خرج القاعدة | شكل (مثلث) | رقم واحد |
| كيف بيطلع الجواب | مركز ثقل الشكل الناتج | متوسط الأرقام حسب قوة كل قاعدة |
| السرعة | أبطأ | أسرع |
| بـ MATLAB | `mamfis` | `sugfis` |

بمتحكمنا، المثلثات NB و NS و Z و PS و PB صاروا أرقام: −1 و −0.5 و 0 و 0.5 و 1.

### الاضطراب والخطأ المستقر

- **الاضطراب:** قوة من برّا بتدفش النظام (متل الطلعة، أو الهوا، أو حمل زيادة على محرك).
- **الخطأ المستقر:** فرق بيضل بين الخرج والمطلوب حتى بعد ما يهدا كل شي.

متحكمنا من الجلسة 4 بيشوف الخطأ وتغيّره بس. لما يجي الاضطراب، بيضل في خطأ صغير ما بيروح، لأنه المتحكم ما «بيتذكّر» إنه الخطأ صرله فترة موجود.

### الحل: التكامل

<Concept term="التكامل" en="Integral">

يعني **نجمع** شي مع الوقت. متل الحصّالة: كل يوم بتحط فيها شوي، فالمجموع بيضل يكبر طول ما عم تحط.

بالمتحكم: طول ما في خطأ (ولو صغير)، المجموع بيكبر، فالدفعة بتكبر لحتى يروح الخطأ تماماً.

**وين بينستخدم؟** مثبّت السرعة بالسيارة على الطلعات، والمكيفات، وتقريباً كل متحكمات المصانع.

</Concept>

منضيف للمتحكم جزء بيجمع الخطأ مع الوقت (**Ki**). طول ما في خطأ، هالجزء بيضل يزيد، لحتى يروح الخطأ تماماً. صار عنا متحكم **Fuzzy-PID**.

## جرّب بالمتصفح

هاد **خيار تاني**: إذا ما عندك MATLAB هلق، أو بدك تفهم الفكرة قبل ما تفتحه. الحسابات هون نفسها يلي بيعملها `simFuzzy`، فالأرقام لازم تطلع متل بعض. بس تذكّر: العملي والتقييم على **MATLAB**.

<FuzzyLab mode="s6" />

**شو تجرّب؟**
- خلي الاضطراب شغّال و **Ki = 0**: الخرج بيوقف عند حوالي **1.21**.
- كبّر **Ki** لـ **1**: الخرج بيرجع لـ **1**، والتجاوز قبل الاضطراب حوالي **10.6%**.
- بدّل لـ **Sugeno**، وافتح «شو عم يصير جوّا المتحكم؟»: السطح صار مستوي متل لوح مائل، والاستجابة قريبة كتير من Mamdani.

## خطوات العملي

### 1. ابنِ المتحكمين

```matlab
mam = buildFuzzyPD(3);              % Mamdani (متل الجلسة 4)
sug = buildFuzzyPD(3, 'sugeno');    % نفس القواعد بس Sugeno
```

### 2. قارن الأجوبة

```matlab
evalfis(mam, [0.5 -0.2])
evalfis(sug, [0.5 -0.2])

evalfis(mam, [1 1])
evalfis(sug, [1 1])
```

**شو لازم تشوف:** الأجوبة **قريبة بس مش متطابقة**. مثلاً عند `[1 1]`: Mamdani بيعطي 0.84، و Sugeno بيعطي 1.

### 3. قارن السطحين والاستجابة

```matlab
figure;
subplot(1,2,1); gensurf(mam); title('Mamdani');
subplot(1,2,2); gensurf(sug); title('Sugeno');

simFuzzy(mam, 1, 0.3, 4)
simFuzzy(sug, 1, 0.3, 4)
```

**شو لازم تشوف:** سطح Sugeno **مستوي تماماً** (متل لوح مائل)، وسطح Mamdani فيه انحناءات خفيفة. والاستجابتين قريبين كتير.

### 4. ضيف اضطراب

منضيف اضطراب بقيمة 0.5 بيبدأ عند الثانية 5:

```matlab
simFuzzy(mam, 1, 0.3, 4, 'Disturbance', 0.5, 'Time', 20)
```

**شو لازم تشوف:** الخرج بيوصل لـ 1، وعند الثانية 5 **بينط لفوق**، وبيستقر عند حوالي **1.21** بدل 1. هاد هو الخطأ المستقر.

### 5. ضيف التكامل

```matlab
simFuzzy(mam, 1, 0.3, 4, 'Disturbance', 0.5, 'Time', 20, 'Ki', 1)
```

**شو لازم تشوف:** بعد الاضطراب الخرج بيطلع شوي، بس **بيرجع لـ 1**. 

<Aside type="note" title="التكامل الذكي">
`simFuzzy` بيشغّل التكامل بس لما يكون الخطأ **صغير**. ليش؟ لأنه بأول المحاكاة الخطأ كبير، ولو ضل التكامل شغّال، كان رح يجمع كتير ويعمل تجاوز كبير.
</Aside>

### 6. نفس الشي بـ Simulink

<Steps>

1. افتح `lab04_fuzzy.slx` واحفظه باسم `lab06_fuzzy_pid.slx`.

2. **الاضطراب:** ضيف بلوك **Step** (`Step time = 5`، `Final value = 0.5`)، وبلوك **Sum** (`++`) قبل الـ Transfer Fcn مباشرة. وصّل خرج الـ Saturation والـ Step عالـ Sum، وخرج الـ Sum عالـ Transfer Fcn.

3. اضغط Run. **شو لازم تشوف:** نفس الخطوة 4 (الخرج بيستقر فوق 1).

4. **التكامل:** ضيف بلوك <Term t="Integrator" def="بلوك بيجمع الإشارة مع الوقت. هو التكامل نفسه بـ Simulink." /> وبلوك **Gain** (اكتب جواته `Ki`)، وبلوك **Sum** (`++`):

   ```text
   الخطأ ─► Integrator ─► Gain(Ki) ─┐
                                    ├─► Sum ─► Saturation(±5)
   Fuzzy ─► Gain(Ku) ───────────────┘
   ```

5. اكتب `Ki = 0.5;` بالـ Command Window واضغط Run.

</Steps>

**شو لازم تشوف:** الخرج بيرجع لـ 1 بعد الاضطراب، بس **أبطأ** من `simFuzzy`، وبتجاوز أكبر بالبداية (حوالي 20%). السبب إنه التكامل هون شغّال **دايماً**، مش بس لما يكون الخطأ صغير.

## النتيجة المتوقعة

| التجربة | النتيجة |
| --- | --- |
| Mamdani بدون اضطراب | تجاوز ≈ 0.9%، استقرار ≈ 2.1 s |
| Sugeno بدون اضطراب | تجاوز ≈ 1.5%، استقرار ≈ 1.9 s |
| Mamdani مع اضطراب، بدون تكامل | الخرج بيستقر عند ≈ **1.21** (خطأ مستقر) |
| Mamdani مع اضطراب، مع تكامل `Ki = 1` | الخرج بيرجع لـ **1.00**، والتجاوز بالبداية صار ≈ 10.6% |

يعني التكامل **بيلغي الخطأ**، بس **بيكلّف** شوية تجاوز.

## أخطاء شائعة

| الخطأ | السبب والحل |
| --- | --- |
| `Undefined function 'sugfis'` | نسخة MATLAB قديمة (قبل 2018b). |
| الاضطراب ما بيبيّن | نسيت `'Time', 20`، فالمحاكاة وقفت عند 10 ثواني قبل ما يهدا الخرج. |
| بـ Simulink التجاوز صار كبير كتير | `Ki` كبير. جرّب `Ki = 0.2` أو `0.3`. |
| بـ Simulink الخرج ما رجع لـ 1 | زيد **Stop Time** لـ 30، التكامل البسيط بطيء. |

2. جرّب الاضطراب مع Sugeno: `simFuzzy(sug, 1, 0.3, 4, 'Disturbance', 0.5, 'Time', 20, 'Ki', 1)`.
3. سلّم رسمتين: قبل التكامل وبعده.

<details class="answer">

</details>

<details class="answer">
<summary>شو بيعمل التكامل ببساطة؟</summary>

بيجمع الخطأ مع الوقت. طول ما في خطأ، الدفعة بتزيد شوي شوي، لحتى يروح الخطأ تماماً. متل لما تزيد دعسة البنزين شوي شوي على الطلعة.
</details>
