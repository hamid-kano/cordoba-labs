## أنظمة التحكم

| المصطلح | بالإنكليزية | معناه ببساطة |
| --- | --- | --- |
| نظام | System / Plant | الشيء الذي نريد التحكم فيه: محرك، خزان، فرن... |
| الدخل | Input | ما نعطيه للنظام (جهد، تدفق، حرارة...) |
| الخرج | Output | ما يخرج من النظام ونقيسه |
| تابع التحويل | Transfer Function | طريقة لكتابة النظام على شكل «كسر» في MATLAB (`tf`) |
| المتحكم | Controller | «العقل» الذي يقرّر ماذا نعطي للنظام |
| المطلوب / المرجع | Reference / Setpoint | القيمة التي نريد أن يصل إليها الخرج |
| الخطأ | Error (e) | المطلوب ناقص الخرج |
| تغيّر الخطأ | Change of error (de) | مقدار زيادة الخطأ أو نقصانه في كل ثانية |
| حلقة مغلقة | Closed Loop | يقيس المتحكم الخرج ويصحّح حسب الخطأ |
| التغذية الراجعة | Feedback | الخط الذي يعيد الخرج لمقارنته بالمطلوب |
| استجابة الخطوة | Step Response | سلوك النظام عندما نطلب منه فجأة الانتقال إلى قيمة جديدة |
| التجاوز | Overshoot | مقدار ارتفاع الخرج **فوق** المطلوب قبل أن يعود (بالنسبة المئوية) |
| زمن الاستقرار | Settling Time | الوقت اللازم حتى يهدأ الخرج ويصبح قريباً جداً من المطلوب |
| زمن الصعود | Rise Time | الوقت الذي يحتاجه الخرج ليرتفع من 10% إلى 90% من المطلوب |
| القمة | Peak | أعلى قيمة يصل إليها الخرج، ووقتها هو زمن القمة (Peak Time) |
| الخطأ المستقر | Steady-State Error | فرق يبقى بين الخرج والمطلوب حتى بعد أن يهدأ كل شيء |
| الاضطراب | Disturbance | قوة خارجية تؤثّر في النظام (مرتفع، رياح، حمل...) |
| المشغّل | Actuator | الجهاز الذي ينفّذ أمر المتحكم: محرك، مضخة، مدفأة |
| حدود المشغّل / الإشباع | Saturation | أكبر وأصغر قيمة يستطيع المشغّل إعطاءها |
| التراكم | Windup | يستمر التكامل في الجمع بينما المشغّل عند حدّه، فيسبّب تجاوزاً كبيراً |

## متحكم PID

| المصطلح | بالإنكليزية | معناه ببساطة |
| --- | --- | --- |
| P (تناسبي) | Proportional | دفعة تتناسب مع حجم الخطأ **الآن** |
| I (تكاملي) | Integral | دفعة تزيد تدريجياً ما دام **هناك** خطأ، وتلغي الخطأ المستقر |
| D (تفاضلي) | Derivative | «فرامل» عندما يقترب الخرج بسرعة، وتخفّف التجاوز |
| التفاضل | Derivative | مقدار تغيّر الشيء **الآن** (مثل عدّاد السرعة). وفي الرسم: ميل الخط |
| التكامل | Integral | مقدار ما تجمّع من الشيء **حتى الآن** (مثل عدّاد المسافة أو الحصّالة). وفي الرسم: المساحة تحت الخط |
| الضبط | Tuning | اختيار أرقام المتحكم حتى يعمل جيداً |

## المنطق الضبابي

| المصطلح | بالإنكليزية | معناه ببساطة |
| --- | --- | --- |
| المنطق الضبابي | Fuzzy Logic | منطق يسمح بـ«قليلاً» و«كثيراً» بدل الصحيح أو الخاطئ فقط |
| مجموعة ضبابية | Fuzzy Set | وصف بالكلام مثل «حار» أو «سريع» أو «خطأ موجب» |
| درجة الانتماء | Membership Degree | مقدار انتماء القيمة إلى مجموعة (رقم من 0 إلى 1) |
| دالة الانتماء | Membership Function | الرسم الذي يعطي درجة الانتماء لكل قيمة (`trimf` مثلث، `trapmf` شبه منحرف) |
| قاعدة | Rule | جملة «إذا ... فإن ...»، مثلاً: إذا كان الجو حاراً فالمروحة سريعة |
| التضبيب | Fuzzification | حساب درجات الانتماء للمدخلات |
| قوة القاعدة | Firing Strength | مقدار «عمل» القاعدة (من 0 إلى 1) |
| AND | AND | في المنطق الضبابي: نأخذ **الأصغر** بين الدرجتين |
| إزالة التضبيب | Defuzzification | تحويل النتيجة الضبابية إلى رقم واحد |
| مركز الثقل | Centroid | نقطة توازن الشكل الناتج، وهي الجواب النهائي في Mamdani |
| نظام الاستدلال الضبابي | FIS | المتحكم الضبابي كاملاً: المدخلات والخرج والقواعد (`fis` في MATLAB) |
| Mamdani | Mamdani | نوع يكون خرج كل قاعدة فيه **شكلاً** (مثلثاً) |
| Sugeno | Sugeno | نوع يكون خرج كل قاعدة فيه **رقماً**، وهو أبسط وأسرع |
| سطح التحكم | Control Surface | رسم يبيّن خرج المتحكم لكل المدخلات (`gensurf`) |
| أزرار الضبط | Scaling Gains | `Ke` و `Kd` و `Ku`: تربط المتحكم (من −1 إلى 1) بالنظام الحقيقي |

## MATLAB و Simulink

| المصطلح | معناه ببساطة |
| --- | --- |
| Command Window | المكان الذي تكتب فيه الأوامر |
| Workspace | قائمة المتغيرات التي عرّفتها |
| Current Folder | المجلد الذي يعمل فيه MATLAB، ويجب أن تكون ملفاتك فيه |
| Script | ملف `.m` فيه أوامر تُنفَّذ بالتتابع |
| Section (`%%`) | جزء من الملف يمكنك تشغيله وحده |
| Block (بلوك) | «صندوق» في Simulink يؤدي مهمة واحدة |
| Scope | بلوك يشبه الشاشة ويرسم الإشارة |
| Mux | بلوك يجمع عدة إشارات في خط واحد |
| `simFuzzy` | ملف مساعد خاص بالمادة: يجرّب المتحكم الضبابي بسطر واحد |
| `buildFuzzyPD` | ملف مساعد خاص بالمادة: يبني متحكم الجلسة 4 جاهزاً |
