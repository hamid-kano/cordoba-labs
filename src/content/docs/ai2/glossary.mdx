إذا مرّت معك كلمة وما فهمتها، دوّر عليها هون (أو استخدم البحث فوق). وإذا بدك شرح أطول لرموز PID والمتحكم الضبابي وشو غايتها، شوف [PID والضبابي ببساطة](../pid-fuzzy/).

## أنظمة التحكم

| المصطلح | بالإنكليزي | شو يعني ببساطة |
| --- | --- | --- |
| نظام | System / Plant | الشي يلي بدنا نتحكم فيه: محرك، خزان، فرن... |
| الدخل | Input | يلي منعطيه للنظام (جهد، تدفق، حرارة...) |
| الخرج | Output | يلي بيطلع من النظام ومنقيسه |
| تابع التحويل | Transfer Function | طريقة لكتابة النظام كـ «كسر» بـ MATLAB (`tf`) |
| المتحكم | Controller | «العقل» يلي بيقرر شو نعطي للنظام |
| المطلوب / المرجع | Reference / Setpoint | القيمة يلي بدنا الخرج يوصلها |
| الخطأ | Error (e) | المطلوب ناقص الخرج |
| تغيّر الخطأ | Change of error (de) | قديش الخطأ عم يزيد أو ينقص بكل ثانية |
| حلقة مغلقة | Closed Loop | المتحكم بيقيس الخرج وبيصحّح حسب الخطأ |
| التغذية الراجعة | Feedback | الخط يلي بيرجّع الخرج للمقارنة مع المطلوب |
| استجابة الخطوة | Step Response | كيف بيتصرف النظام لما نطلب منه فجأة يروح لقيمة جديدة |
| التجاوز | Overshoot | قديش الخرج طلع **فوق** المطلوب قبل ما يرجع (بالنسبة المئوية) |
| زمن الاستقرار | Settling Time | الوقت لحتى يهدا الخرج ويصير قريب كتير من المطلوب |
| الخطأ المستقر | Steady-State Error | فرق بيضل بين الخرج والمطلوب حتى بعد ما يهدا كل شي |
| الاضطراب | Disturbance | قوة من برّا بتأثر على النظام (طلعة، هوا، حمل...) |
| المشغّل | Actuator | يلي بينفّذ أمر المتحكم: محرك، مضخة، مدفأة |
| حدود المشغّل / الإشباع | Saturation | أكبر وأصغر قيمة بيقدر يعطيها المشغّل |
| التراكم | Windup | التكامل بيضل يجمع وقت المشغّل على حده، فبيعمل تجاوز كبير |

## متحكم PID

| المصطلح | بالإنكليزي | شو يعني ببساطة |
| --- | --- | --- |
| P (تناسبي) | Proportional | دفعة على قد ما الخطأ كبير **هلق** |
| I (تكاملي) | Integral | دفعة بتزيد شوي شوي طول ما **في** خطأ. بتلغي الخطأ المستقر |
| D (تفاضلي) | Derivative | «فرامل» لما الخرج يقرّب بسرعة. بتخفف التجاوز |
| التفاضل | Derivative | قديش الشي عم يتغيّر **هلق** (متل عدّاد السرعة). بالرسمة: ميل الخط |
| التكامل | Integral | قديش الشي تجمّع **لهلق** (متل عدّاد المسافة أو الحصّالة). بالرسمة: المساحة تحت الخط |
| الضبط | Tuning | اختيار أرقام المتحكم لحتى يشتغل منيح |

## المنطق الضبابي

| المصطلح | بالإنكليزي | شو يعني ببساطة |
| --- | --- | --- |
| المنطق الضبابي | Fuzzy Logic | منطق بيسمح بالـ «شوي» و«كتير» بدل صح أو غلط بس |
| مجموعة ضبابية | Fuzzy Set | وصف بالكلام متل «حار» أو «سريع» أو «خطأ موجب» |
| درجة الانتماء | Membership Degree | قديش القيمة بتنتمي لمجموعة (رقم من 0 لـ 1) |
| دالة الانتماء | Membership Function | الرسمة يلي بتعطي درجة الانتماء لكل قيمة (`trimf` مثلث، `trapmf` شبه منحرف) |
| قاعدة | Rule | جملة «إذا ... فـ ...»، مثلاً: إذا الجو حار فالمروحة سريعة |
| التضبيب | Fuzzification | حساب درجات الانتماء للمدخلات |
| قوة القاعدة | Firing Strength | قديش القاعدة «شغّالة» (من 0 لـ 1) |
| AND | AND | بالمنطق الضبابي: منوخد **الأصغر** بين الدرجتين |
| إزالة التضبيب | Defuzzification | تحويل النتيجة الضبابية لرقم واحد |
| مركز الثقل | Centroid | نقطة توازن الشكل الناتج، وهي الجواب النهائي بـ Mamdani |
| نظام الاستدلال الضبابي | FIS | المتحكم الضبابي كامل: المدخلات والخرج والقواعد (`fis` بـ MATLAB) |
| Mamdani | Mamdani | نوع خرج كل قاعدة فيه **شكل** (مثلث) |
| Sugeno | Sugeno | نوع خرج كل قاعدة فيه **رقم**. أبسط وأسرع |
| سطح التحكم | Control Surface | رسمة بتبيّن خرج المتحكم لكل المدخلات (`gensurf`) |
| أزرار الضبط | Scaling Gains | `Ke` و `Kd` و `Ku`: بيربطوا المتحكم (من −1 لـ 1) بالنظام الحقيقي |

## MATLAB و Simulink

| المصطلح | شو يعني ببساطة |
| --- | --- |
| Command Window | المكان يلي بتكتب فيه الأوامر |
| Workspace | قائمة المتغيرات يلي عرّفتها |
| Current Folder | المجلد يلي MATLAB عم يشتغل فيه. لازم تكون ملفاتك فيه |
| Script | ملف `.m` فيه أوامر بتنفذ ورا بعض |
| Section (`%%`) | جزء من الملف فيك تشغّله لحاله |
| Block (بلوك) | «صندوق» بـ Simulink بيعمل شغلة وحدة |
| Scope | بلوك متل شاشة بيرسم الإشارة |
| Mux | بلوك بيجمع كذا إشارة بخط واحد |
| `simFuzzy` | ملف مساعد خاص بالمادة: بيجرّب المتحكم الضبابي بسطر واحد |
| `buildFuzzyPD` | ملف مساعد خاص بالمادة: بيبني متحكم الجلسة 4 جاهز |
