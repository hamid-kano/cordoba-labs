<Aside type="tip" title="الفكرة ببساطة">
ضبط المتحكم يشبه ضبط **الصوت ومكبّر الصوت** في جهاز ستيريو: لديك ثلاثة أزرار (`Ke` و `Kd` و `Ku`). والقاعدة الذهبية: **غيّر زراً واحداً فقط في كل مرة**، ولاحظ ما حدث، وسجّله.
</Aside>

## أهداف الجلسة

- معرفة وظيفة كل زر من الأزرار الثلاثة.
- ملء جدول تجارب واستخراج قواعد ضبط بسيطة منه.
- مقارنة متحكم بـ **ثلاث** مجموعات لكل مدخل مع متحكم بـ **خمس** مجموعات.
- ضبط المتحكم حتى يحقق طلباً محدداً.

## ملخص نظري

### الأزرار الثلاثة

<Concept term="ضبط المتحكم" en="Tuning">

أي أن نغيّر الأزرار حتى تصبح الاستجابة كما نريد. مثلما تضبط الصوت والإضاءة في التلفاز: الجهاز نفسه، لكن النتيجة تتغيّر كثيراً حسب الأزرار.

**القاعدة الذهبية:** غيّر **زراً واحداً** في كل مرة، ولاحظ ما حدث للتجاوز وزمن الاستقرار. فإذا غيّرت زرين معاً، لن تعرف أيهما السبب.

</Concept>

| الزر | يؤثّر في | عندما تكبّره |
| --- | --- | --- |
| `Ku` | قوة الدفعة | تصبح الاستجابة **أسرع**، لكن المحرك يعمل بقوة أكبر |
| `Kd` | الفرامل | **يقلّ** التجاوز، لكن إذا أكثرت تصبح الاستجابة بطيئة |
| `Ke` | «حساسية» المتحكم للخطأ | أسرع، لكن التجاوز **يزيد** |

### كلمتان جديدتان

- **ثلاث مجموعات:** لكل مدخل N و Z و P (مثل الجلسة 4)، أي 9 قواعد.
- **خمس مجموعات:** لكل مدخل <Term t="NB" en="Negative Big" def="سالب كبير." /> و <Term t="NS" en="Negative Small" def="سالب صغير." /> و Z و <Term t="PS" en="Positive Small" def="موجب صغير." /> و <Term t="PB" en="Positive Big" def="موجب كبير." />، أي 25 قاعدة. فيصبح المتحكم «أدق» في التمييز بين الخطأ الصغير والكبير.

لن تكتب القواعد الـ 25 يدوياً، فالملف `buildFuzzyPD.m` يبنيها نيابةً عنك.

## جرّب في المتصفح

هذا **خيار إضافي**: إذا لم يكن لديك <Term t="MATLAB" en="MATrix LABoratory" def="برنامج للحسابات والرسوم والمحاكاة، ومعنى اسمه مختبر المصفوفات." /> الآن، أو أردت فهم الفكرة قبل فتحه. الحسابات هنا هي نفسها التي يجريها `simFuzzy`، فيجب أن تتطابق الأرقام. لكن تذكّر: العملي والتقييم على **MATLAB**.

<FuzzyLab mode="s5" />

**ماذا تجرّب؟**
- غيّر زراً واحداً فقط في كل مرة، وثبّت الرسم قبل التغيير لتقارن.
- حاول حل **التحدي** (تجاوز أقل من 2%، واستقرار أسرع من 1.5 ثانية). ستظهر لك رسالة عند النجاح.
- بدّل بين **ثلاث** و**خمس** مجموعات بالأزرار نفسها، وقارن السطحين.

## خطوات العملي

### 1. جهّز المتحكمين

```matlab
fis3 = buildFuzzyPD(3);       % متحكم الجلسة 4 نفسه
fis5 = buildFuzzyPD(5);       % خمس مجموعات و 25 قاعدة
simFuzzy(fis3, 1, 0.3, 4)     % تأكّد أنه يعطي نتيجة الجلسة 4 نفسها
```

**ماذا يجب أن ترى؟** تجاوز ≈ 0.9% وزمن استقرار ≈ 2.1 s.

### 2. جرّب الزر `Ku`

غيّر `Ku` فقط، واترك الباقي كما هو:

```matlab
simFuzzy(fis3, 1, 0.3, 2)
simFuzzy(fis3, 1, 0.3, 8)
```

### 3. جرّب الزر `Kd`

```matlab
simFuzzy(fis3, 1, 0.1, 4)
simFuzzy(fis3, 1, 0.6, 4)
```

### 4. جرّب الزر `Ke`

```matlab
simFuzzy(fis3, 0.5, 0.3, 4)
simFuzzy(fis3, 2,   0.3, 4)
```

### 5. املأ الجدول

بعد كل تجربة يطبع لك `simFuzzy` الأرقام. انقلها إلى هنا:

| التجربة | `Ke` | `Kd` | `Ku` | التجاوز % | زمن الاستقرار (s) | أكبر \|u\| |
| --- | --- | --- | --- | --- | --- | --- |
| الأساس | 1 | 0.3 | 4 | | | |
| `Ku` صغير | 1 | 0.3 | 2 | | | |
| `Ku` كبير | 1 | 0.3 | 8 | | | |
| `Kd` صغير | 1 | 0.1 | 4 | | | |
| `Kd` كبير | 1 | 0.6 | 4 | | | |
| `Ke` صغير | 0.5 | 0.3 | 4 | | | |
| `Ke` كبير | 2 | 0.3 | 4 | | | |

### 6. ثلاث مجموعات أم خمس؟

```matlab
figure;
subplot(1,2,1); gensurf(fis3); title('3 مجموعات');
subplot(1,2,2); gensurf(fis5); title('5 مجموعات');

simFuzzy(fis5, 1, 0.3, 4)
```

**ماذا يجب أن ترى؟** سطح الخمس مجموعات **أحدّ** في الوسط، والاستجابة **أسرع** بالأزرار نفسها.

### 7. التحدي

المطلوب باستخدام `fis3`: تجاوز **أقل من 2%**، وزمن استقرار **أقل من 1.5 ثانية**، وأكبر |u| **لا يتجاوز 5**.

<Steps>

1. ابدأ من الأساس (1، 0.3، 4).
2. تريد استجابة أسرع؟ ما الزر الذي يسرّعها؟ كبّره تدريجياً.
3. بعد كل تجربة تأكّد من الشروط الثلاثة.

</Steps>

<details class="answer">
<summary>الحل (افتحه بعد أن تجرّب)</summary>

`simFuzzy(fis3, 1, 0.3, 8)`: التجاوز ≈ 0.9%، وزمن الاستقرار ≈ 1.42 s، وأكبر |u| = 4. كبّرنا `Ku` فقط.
</details>

## النتيجة المتوقعة

| التجربة | التجاوز | زمن الاستقرار | أكبر \|u\| |
| --- | --- | --- | --- |
| الأساس (1، 0.3، 4) | ≈ 0.9% | ≈ 2.1 s | 2 |
| `Ku = 2` | ≈ 0.2% | ≈ 3.6 s | 1 |
| `Ku = 8` | ≈ 0.9% | ≈ 1.4 s | 4 |
| `Kd = 0.1` | ≈ 8.6% | ≈ 2.8 s | 2 |
| `Kd = 0.6` | 0% | ≈ 3.6 s | 2 |
| `Ke = 0.5` | 0% | ≈ 4.7 s | 1 |
| `Ke = 2` | ≈ 7.8% | ≈ 2.3 s | 2 |
| خمس مجموعات (1، 0.3، 4) | ≈ 1.2% | ≈ 1.6 s | ≈ 2.7 |

**قواعد الضبط التي استنتجناها:**

| المشكلة | الحل |
| --- | --- |
| الاستجابة بطيئة | كبّر `Ku` |
| يوجد تجاوز كبير | كبّر `Kd` |
| بطيئة وبدون أي تجاوز | صغّر `Kd` قليلاً، أو كبّر `Ke` |
| إشارة التحكم أكبر من حد المحرك | صغّر `Ku` |

## أخطاء شائعة

| الخطأ | السبب والحل |
| --- | --- |
| `Undefined function 'buildFuzzyPD'` | الملف `buildFuzzyPD.m` ليس في الـ Current Folder. |
| غيّرت زرين معاً ولم تعرف أيهما أثّر | عُد إلى الأساس، وغيّر **زراً واحداً** فقط. |
| ظهر زمن الاستقرار `NaN` | لم يستقر الخرج خلال 10 ثوانٍ. زِد الوقت: `simFuzzy(fis3, 1, 0.3, 4, 'Time', 20)` |
| المحاكاة بطيئة قليلاً | أمر طبيعي، فكل تجربة تستغرق بضع ثوانٍ. |
