<Aside type="tip" title="الفكرة ببساطة">
ضبط المتحكم متل ضبط **صوت ومكبّر** بجهاز ستيريو: عندك 3 أزرار (`Ke` و `Kd` و `Ku`). القاعدة الذهبية: **غيّر زر واحد بس بكل مرة**، وشوف شو صار، وسجّل.
</Aside>

## أهداف الجلسة

- تعرف شو بيعمل كل زر من الأزرار التلاتة.
- تملى جدول تجارب وتطلع منه قواعد ضبط بسيطة.
- تقارن متحكم بـ **3** مجموعات لكل مدخل مع متحكم بـ **5** مجموعات.
- تضبط المتحكم لحتى يحقق طلب محدد.

## المتطلبات

- إنهاء [الجلسة 4](../lab-04-fuzzy-pd-controller/).
- الملفين المساعدين بمجلد `AI2-Lab`: [simFuzzy.m](../../files/ai2/simFuzzy.m) و [buildFuzzyPD.m](../../files/ai2/buildFuzzyPD.m).

## ملخص نظري

### الأزرار التلاتة

| الزر | بيأثر على | لما تكبّره |
| --- | --- | --- |
| `Ku` | قوة الدفعة | الاستجابة **أسرع**، بس المحرك بيشتغل أقوى |
| `Kd` | الفرامل | التجاوز **بيقلّ**، بس إذا كتّرت بيصير بطيء |
| `Ke` | قديش المتحكم «حساس» للخطأ | أسرع، بس التجاوز **بيزيد** |

### كلمتين جداد

- **3 مجموعات:** كل مدخل إله N و Z و P (متل الجلسة 4)، يعني 9 قواعد.
- **5 مجموعات:** كل مدخل إله NB و NS و Z و PS و PB، يعني 25 قاعدة. المتحكم بيصير «أدق» بالتمييز بين الخطأ الصغير والكبير.

ما رح تكتب الـ 25 قاعدة بإيدك. الملف `buildFuzzyPD.m` بيبنيهن عنك.

## خطوات العملي

### 1. جهّز المتحكمين

```matlab
fis3 = buildFuzzyPD(3);       % نفس متحكم الجلسة 4
fis5 = buildFuzzyPD(5);       % 5 مجموعات و 25 قاعدة
simFuzzy(fis3, 1, 0.3, 4)     % تأكد إنه بيعطي نفس نتيجة الجلسة 4
```

**شو لازم تشوف:** تجاوز ≈ 0.9% وزمن استقرار ≈ 2.1 s.

### 2. جرّب الزر `Ku`

غيّر `Ku` بس، وخلي الباقي متل ما هو:

```matlab
simFuzzy(fis3, 1, 0.3, 2)
simFuzzy(fis3, 1, 0.3, 8)
```

### 3. جرّب الزر `Kd`

```matlab
simFuzzy(fis3, 1, 0.1, 4)
simFuzzy(fis3, 1, 0.6, 4)
```

### 4. جرّب الزر `Ke`

```matlab
simFuzzy(fis3, 0.5, 0.3, 4)
simFuzzy(fis3, 2,   0.3, 4)
```

### 5. عبّي الجدول

بعد كل تجربة، `simFuzzy` بيطبعلك الأرقام. انقلهن هون:

| التجربة | `Ke` | `Kd` | `Ku` | التجاوز % | زمن الاستقرار (s) | أكبر \|u\| |
| --- | --- | --- | --- | --- | --- | --- |
| الأساس | 1 | 0.3 | 4 | | | |
| `Ku` صغير | 1 | 0.3 | 2 | | | |
| `Ku` كبير | 1 | 0.3 | 8 | | | |
| `Kd` صغير | 1 | 0.1 | 4 | | | |
| `Kd` كبير | 1 | 0.6 | 4 | | | |
| `Ke` صغير | 0.5 | 0.3 | 4 | | | |
| `Ke` كبير | 2 | 0.3 | 4 | | | |

### 6. 3 مجموعات أو 5؟

```matlab
figure;
subplot(1,2,1); gensurf(fis3); title('3 مجموعات');
subplot(1,2,2); gensurf(fis5); title('5 مجموعات');

simFuzzy(fis5, 1, 0.3, 4)
```

**شو لازم تشوف:** سطح الـ 5 مجموعات **أحدّ** بالنص، والاستجابة **أسرع** بنفس الأزرار.

### 7. التحدي

المطلوب بـ `fis3`: تجاوز **أقل من 2%**، وزمن استقرار **أقل من 1.5 ثانية**، وأكبر |u| **ما يتجاوز 5**.

<Steps>

1. ابدأ من الأساس (1، 0.3، 4).
2. بدك أسرع؟ شو الزر يلي بيسرّع؟ كبّره شوي شوي.
3. بعد كل تجربة تأكد من التلات شروط.

</Steps>

<details class="answer">
<summary>الحل (افتحه بعد ما تجرب)</summary>

`simFuzzy(fis3, 1, 0.3, 8)`: التجاوز ≈ 0.9%، وزمن الاستقرار ≈ 1.42 s، وأكبر |u| = 4. كبّرنا `Ku` بس.
</details>

## النتيجة المتوقعة

| التجربة | التجاوز | زمن الاستقرار | أكبر \|u\| |
| --- | --- | --- | --- |
| الأساس (1، 0.3، 4) | ≈ 0.9% | ≈ 2.1 s | 2 |
| `Ku = 2` | ≈ 0.2% | ≈ 3.6 s | 1 |
| `Ku = 8` | ≈ 0.9% | ≈ 1.4 s | 4 |
| `Kd = 0.1` | ≈ 8.6% | ≈ 2.8 s | 2 |
| `Kd = 0.6` | 0% | ≈ 3.6 s | 2 |
| `Ke = 0.5` | 0% | ≈ 4.7 s | 1 |
| `Ke = 2` | ≈ 7.8% | ≈ 2.3 s | 2 |
| 5 مجموعات (1، 0.3، 4) | ≈ 1.2% | ≈ 1.6 s | ≈ 2.7 |

**قواعد الضبط يلي طلعنا فيها:**

| المشكلة | الحل |
| --- | --- |
| الاستجابة بطيئة | كبّر `Ku` |
| في تجاوز كبير | كبّر `Kd` |
| بطيئة وبدون تجاوز أبداً | صغّر `Kd` شوي، أو كبّر `Ke` |
| إشارة التحكم أكبر من حد المحرك | صغّر `Ku` |

## أخطاء شائعة

| الخطأ | السبب والحل |
| --- | --- |
| `Undefined function 'buildFuzzyPD'` | الملف `buildFuzzyPD.m` مو بالـ Current Folder. |
| غيّرت زرّين سوا وما عرفت مين أثّر | ارجع للأساس، وغيّر **زر واحد** بس. |
| زمن الاستقرار طلع `NaN` | الخرج ما استقر خلال 10 ثواني. زيد الوقت: `simFuzzy(fis3, 1, 0.3, 4, 'Time', 20)` |
| المحاكاة بطيئة شوي | طبيعي. كل تجربة بتاخد كم ثانية. |

## الوظيفة

1. عبّي جدول الخطوة 5 كامل، واكتب تحته الخلاصة بـ 3 جمل.
2. حل التحدي بـ `fis5` كمان. هل احتجت `Ku` أصغر ولا أكبر؟ ليش؟
3. سلّم الجدول وصورة لأحسن نتيجة.
