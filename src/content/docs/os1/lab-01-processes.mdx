## أهداف الجلسة

- مراقبة العمليات بالأوامر `ps` و `top` و `pstree`.
- فهم `fork()` وكيف بتنتج عملية ابن.
- استبدال برنامج العملية بـ `exec` وانتظار الابن بـ `wait`.

## المتطلبات

- Ubuntu (جهاز افتراضي أو WSL) مع `gcc`.
- أساسيات لغة C.

## ملخص نظري

### شو هي العملية؟

<Concept term="العملية" en="Process">

**البرنامج** ملف قاعد على القرص وما عم يعمل شي، متل وصفة طبخ بكتاب. **العملية** هي البرنامج وقت يكون **عم يشتغل**، متل الطبّاخ وهو عم يطبخ الوصفة. وفيك تفتح نفس البرنامج مرتين، فبيصير عندك عمليتين.

كل عملية إلها رقم مميز اسمه **PID**، ورقم أبوها (يلي شغّلها) اسمه **PPID**.

</Concept>

### التلات أوامر الأساسية

<Concept term="نسخ العملية" en="fork()">

`fork()` بتعمل **نسخة طبق الأصل** من العملية: الأصل اسمه **الأب**، والنسخة اسمها **الابن**. والغريب إنها بترجع **مرتين**: عند الابن بترجع `0`، وعند الأب بترجع رقم الابن. هيك كل واحد بيعرف مين هو.

</Concept>

<Concept term="تبديل البرنامج" en="exec()">

`exec` بتبدّل البرنامج جوّا العملية ببرنامج جديد. متل ممثل بيغيّر دوره بنص المسرحية: نفس الشخص (نفس PID)، بس دور جديد. وما بترجع أبداً، إلا إذا فشلت.

</Concept>

<Concept term="انتظار الابن" en="wait()">

`wait()` بتخلي الأب **يستنى** ابنه لحتى يخلص، وبتقرأ كيف خلص. إذا الأب ما استنى، الابن بيخلص بس بيضل اسمه بجدول العمليات، وبيصير <Term t="Zombie" def="عملية خلصت شغلها، بس أبوها لسا ما سأل عنها بـ wait، فبيضل إلها سطر بجدول العمليات. متل طالب خلص الامتحان بس لسا ما سلّم ورقته." />.

</Concept>

## خطوات العملي

### 1. مراقبة العمليات

افتح <Term t="الطرفية" en="Terminal" def="شاشة بتكتب فيها أوامر بالكلام بدل ما تكبس بالماوس. بـ Ubuntu بتفتحها بـ Ctrl+Alt+T." /> واكتب:

```bash
ps -ef | head          # كل العمليات
ps -o pid,ppid,cmd     # عمليات الطرفية الحالية مع رقم الأب
pstree -p | head -20   # شجرة العمليات
top                    # مراقبة حية (q للخروج)
```

### 2. أول `fork`

<Steps>

1. أنشئ الملف `fork_demo.c`:

   ```c
   #include <stdio.h>
   #include <stdlib.h>
   #include <unistd.h>
   #include <sys/wait.h>

   int main(void) {
       pid_t pid = fork();

       if (pid < 0) {
           perror("fork");
           exit(1);
       } else if (pid == 0) {
           printf("Child:  PID=%d, PPID=%d\n", getpid(), getppid());
           execlp("ls", "ls", "-l", NULL);
           perror("exec");          /* ما بتوصل لهون إلا إذا فشل exec */
           exit(1);
       } else {
           int status;
           wait(&status);
           printf("Parent: PID=%d, child %d finished with code %d\n",
                  getpid(), pid, WEXITSTATUS(status));
       }
       return 0;
   }
   ```

2. ترجم وشغّل:

   ```bash
   gcc fork_demo.c -o fork_demo
   ./fork_demo
   ```

</Steps>

## أخطاء شائعة

| الخطأ | السبب والحل |
| --- | --- |
| `implicit declaration of function 'fork'` | ناقصك `#include <unistd.h>`. |
| `implicit declaration of function 'wait'` | ناقصك `#include <sys/wait.h>`. |
| رسالة الأب بتطلع قبل خرج `ls` | نسيت `wait()`. |
