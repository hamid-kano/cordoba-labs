شؤون الطلاب عندها **دفاتر** كتير: دفتر للطلاب، ودفتر للعلامات. إذا غيّر طالب اسمه، لازم يدوّروا عليه بكل الدفاتر ويصلّحوه، ويمكن ينسوا واحد. **قاعدة البيانات** بتحط كل شي بجداول مرتبة ومربوطة ببعض، فالاسم بينكتب **مرة وحدة بس**، وبتسأل أي سؤال («مين نجح بنظم التشغيل؟») وبتجيك الإجابة بثانية.
</Aside>

## أهداف الجلسة

- تعرف ليش قاعدة البيانات أحسن من الملفات العادية.
- تفهم الجدول، والسطر، والعمود، والمفتاح الأساسي والأجنبي.
- تكتب أوامر SQL بسيطة: `SELECT` و `WHERE` و `ORDER BY` و `JOIN` و `INSERT` و `UPDATE`.

## المتطلبات

- المتصفح بس. ما بدك تنزّل شي.

## ملخص نظري

<Concept term="قاعدة البيانات" en="Database">

مجموعة بيانات مرتبة ومحفوظة بطريقة بتسمح لبرامج كتير تستخدمها بنفس الوقت، مع برنامج بيديرها اسمه <Term t="نظام إدارة قواعد البيانات" en="DBMS" def="البرنامج يلي بيحفظ البيانات وبيجاوب على الأسئلة وبيحميها، متل MySQL و SQLite و Oracle." />.

**ليش مش ملفات عادية؟**
- **ما في تكرار:** المعلومة بتنكتب مرة وحدة.
- **ما في تناقض:** ما بيصير اسم الطالب مكتوب بشكلين.
- **أسئلة سهلة:** سطر SQL واحد بدل برنامج كامل.
- **كذا مستخدم بنفس الوقت** بدون ما يخربوا على بعض، وصلاحيات لكل واحد.

**وين؟** بالبنوك، والجامعات، والمستشفيات، وكل تطبيق على موبايلك تقريباً.

</Concept>

### النموذج العلائقي: كل شي جداول

<Concept term="النموذج العلائقي" en="Relational Model">

البيانات محطوطة بـ**جداول**، والجداول مربوطة ببعض بأرقام مشتركة. اخترعه العالم **إدغار كود** سنة 1970، ولليوم هو الأكثر استخداماً.

</Concept>

| الكلمة | يعني | بجدول الطلاب |
| --- | --- | --- |
| **جدول** (Relation) | مجموعة معلومات عن نوع واحد | جدول الطلاب |
| **سطر** (Tuple / Row) | شي واحد | الطالب أحمد |
| **عمود** (Attribute) | صفة | المدينة |
| <Term t="مفتاح أساسي" en="Primary Key" def="عمود قيمته ما بتتكرر أبداً، فبيميّز كل سطر عن غيره. متل الرقم الجامعي." /> | عمود ما بيتكرر | رقم الطالب `id` |
| <Term t="مفتاح أجنبي" en="Foreign Key" def="عمود بجدول بيحمل المفتاح الأساسي لجدول تاني، فبيربطهن. متل رقم الطالب بجدول العلامات." /> | رقم بيأشّر على جدول تاني | `student_id` بجدول العلامات |

### SQL: لغة الأسئلة

<Concept term="SQL" en="Structured Query Language">

اللغة يلي منحكي فيها مع قاعدة البيانات. أوامرها قريبة من الإنكليزي العادي: «اختار الاسم من الطلاب وين المدينة حلب».

</Concept>

| بدي... | الأمر | مثال |
| --- | --- | --- |
| أعرض | `SELECT ... FROM` | `SELECT name FROM students;` |
| أفلتر | `WHERE` | `WHERE city = 'حلب'` |
| أرتّب | `ORDER BY` | `ORDER BY mark DESC` (من الأكبر) |
| أربط جدولين | `JOIN ... ON` | `JOIN students s ON s.id = m.student_id` |
| أحسب | `AVG` و `COUNT` و `MAX` | `SELECT AVG(mark) FROM marks;` |
| أضيف | `INSERT INTO` | `INSERT INTO students VALUES (6, 'نور', 'اللاذقية', 1);` |
| أعدّل | `UPDATE ... SET` | `UPDATE marks SET mark = 60 WHERE ...;` |
| أحذف | `DELETE FROM` | `DELETE FROM marks WHERE mark < 50;` |

<Aside type="caution" title="انتبه لـ WHERE">
`UPDATE` و `DELETE` **بدون** `WHERE` بيغيّروا أو بيمسحوا **كل** الجدول! اكتب الـ `WHERE` دايماً أول شي.
</Aside>

## خطوات العملي

### 1. جرّب SQL

<SqlLab />

<Steps>

1. اكبس **كل الطلاب**. **شو لازم تشوف:** 5 طلاب، لكل واحد رقم واسم ومدينة وسنة.

2. اكبس **طلاب حلب**. **شو لازم تشوف:** أحمد وليلى بس. غيّر `حلب` لـ `دمشق` واكبس ▶.

3. اكبس **اسم الطالب مع علامته**. **شو لازم تشوف:** جدول العلامات صار فيه الأسماء وأسماء المواد بدل الأرقام. هاد هو الـ `JOIN`.

4. اكبس **معدل كل مادة**. **شو لازم تشوف:** نظم التشغيل معدلها **70.6** من 5 طلاب.

5. اكبس **جرّب تكرار المفتاح**. **شو لازم تشوف:** ✘ خطأ، لأنه في طالب رقمه 1 أصلاً. المفتاح الأساسي بيحمي البيانات من التكرار.

6. اكتب بنفسك: `SELECT * FROM marks WHERE mark < 60;` **شو لازم تشوف:** العلامات 55 و 48.

</Steps>

<Aside type="tip">
فيك تكبس **Ctrl + Enter** لتنفّذ، و«رجّع القاعدة» إذا خرّبت شي.
</Aside>

### 2. مسألة محلولة

**السؤال:** اكتب أمر بيعرض أسماء الطلاب يلي علامتهم بنظم التشغيل (المادة رقم 1) **أكبر من 70**، مرتبين من الأعلى.

**الحل خطوة بخطوة:**

1. بدنا الأسماء ← من جدول `students`.
2. والعلامات ← من جدول `marks`.
3. منربطهن برقم الطالب ← `JOIN`.
4. الشرط: المادة 1 والعلامة فوق 70 ← `WHERE`.
5. الترتيب من الأعلى ← `ORDER BY ... DESC`.

```sql
SELECT s.name, m.mark
FROM marks m
JOIN students s ON s.id = m.student_id
WHERE m.course_id = 1 AND m.mark > 70
ORDER BY m.mark DESC;
```

**النتيجة:** سارة 92، أحمد 85، ليلى 73. انسخ الأمر للمحرر وتأكد.

## النتيجة المتوقعة

- بتعرف تحدد المفتاح الأساسي والأجنبي بأي جداول.
- بتكتب `SELECT` مع `WHERE` و `ORDER BY` و `JOIN` بدون مساعدة.

## أخطاء شائعة

| الخطأ | الصح |
| --- | --- |
| النص بدون علامات تنصيص: `city = حلب` | النص بين `'...'`: `city = 'حلب'` |
| نسيت `;` بالآخر | عادة كل أمر بينتهي بـ `;` |
| `UPDATE` بدون `WHERE` | بيعدّل **كل** الأسطر! |
| حطيت اسم الطالب بجدول العلامات | منحط **رقمه** (مفتاح أجنبي)، والاسم منجيبه بالـ `JOIN` |
| `no such column` | اسم العمود غلط. شوف أسماء الأعمدة بـ `SELECT *` |

## الوظيفة

اكتب أوامر SQL للأسئلة هي، وجرّبها بالمحرر:

1. أسماء الطلاب يلي بالسنة **3**.
2. أعلى علامة بجدول العلامات (استخدم `MAX`).
3. عدد الطلاب بكل مدينة (استخدم `GROUP BY city`).
4. ضيف مادة جديدة «قواعد البيانات» رقمها 4 وساعاتها 3.

## أسئلة المراجعة

<details class="answer">
<summary>شو الفرق بين المفتاح الأساسي والأجنبي؟</summary>

الأساسي بيميّز كل سطر بجدوله وما بيتكرر (متل `id` الطالب). الأجنبي عمود بجدول تاني بيحمل هالقيمة ليربط الجدولين (متل `student_id` بالعلامات).
</details>

<details class="answer">
<summary>ليش ما منكتب اسم الطالب بجدول العلامات؟</summary>

لحتى ما يتكرر. إذا تغيّر الاسم، منعدّله بمكان واحد بس، وما بيصير تناقض.
</details>

<details class="answer">
<summary>شو بيعمل هالأمر: <code>DELETE FROM marks;</code>؟</summary>

بيمسح **كل** العلامات، لأنه ما في `WHERE`.
</details>

<details class="answer">
<summary>جدول `marks` مفتاحه الأساسي `(student_id, course_id)` مع بعض. ليش؟</summary>

لأنه الطالب إله علامة وحدة بكل مادة: ما بيصير يتكرر نفس الطالب مع نفس المادة، بس بيصير نفس الطالب مع مواد مختلفة.
</details>
