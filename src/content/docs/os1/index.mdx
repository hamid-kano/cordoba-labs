## أهداف العملي

- استخدام سطر أوامر Linux بثقة.
- إنشاء العمليات وإدارتها باستخدام `fork` و `exec` و `wait`.
- البرمجة بالخيوط (pthreads) وحل مشاكل التزامن.

## البرامج المطلوبة

| البرنامج | ملاحظة |
| --- | --- |
| Ubuntu 22.04 / 24.04 | على جهاز افتراضي أو WSL على ويندوز |
| `gcc` و `make` | `sudo apt install build-essential` |
