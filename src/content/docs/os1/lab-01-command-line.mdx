<Aside type="tip" title="الفكرة ببساطة">
بالمطعم فيك **تأشّر** على صورة الأكلة بالمنيو، أو **تقول** للجرسون بالضبط شو بدك: «شاورما بدون توم وزيادة مخلل». التأشير أسهل بالأول، بس الحكي أسرع وأدق. نفس الشي مع الكمبيوتر: يا بتكبس بالماوس على الأيقونات، يا بتكتب **أوامر**. وأغلب الخوادم بالعالم **ما إلها شاشة أصلاً**، فما في طريقة غير الأوامر.
</Aside>

## أهداف الجلسة

- تعرف شو هو سطر الأوامر وليش لسا منستخدمه.
- تتنقّل بين المجلدات وتعرف وين إنت.
- تعمل ملفات ومجلدات، وتنسخ، وتنقل، وتحذف بالأوامر.
- تعرف الأمر نفسه بـ Linux وبويندوز.

## المتطلبات

- المتصفح بس للطرفية التدريبية.
- لابتوب ويندوز للتجربة الحقيقية (أو اعملها مع رفيقك).

## ملخص نظري

<Concept term="سطر الأوامر" en="Command Line Interface">

طريقة للتعامل مع نظام التشغيل بـ**كتابة أوامر** بدل الكبس بالماوس على الأيقونات. الشاشة السودا يلي بتكتب فيها اسمها <Term t="الطرفية" en="Terminal" def="الشاشة أو البرنامج يلي بتكتب فيه الأوامر. بويندوز اسمها Command Prompt أو PowerShell، وبلينكس Terminal." />، والبرنامج يلي بيفهم أوامرك وبينفّذها اسمه <Term t="الصدفة" en="Shell" def="البرنامج يلي بيقرأ الأمر يلي كتبته، وبيطلب من نظام التشغيل ينفّذه، وبيعرضلك النتيجة. متل bash بلينكس و cmd بويندوز." />.

**ليش لسا منستخدمه؟**
- **أسرع:** أمر واحد بيعمل شغل عشرات الكبسات.
- **الخوادم:** أغلب خوادم الإنترنت لينكس بدون شاشة، والمبرمجين والمسؤولين بيديروها بالأوامر عن بعد.
- **الأتمتة:** بتكتب الأوامر بملف، وبتشغّلها كل يوم لحالها (متل نسخة احتياطية كل ليلة).

**وين بينستخدم؟** إدارة الخوادم، والبرمجة، وحل مشاكل الشبكة (متل `ping` يلي جرّبتها بمادة الشبكات)، والأمن.

</Concept>

### شكل الأمر

```bash
cp  notes.txt  backup.txt
```

| الجزء | يعني | هون |
| --- | --- | --- |
| **الأمر** | شو بدك تعمل | `cp` (انسخ) |
| **المعاملات** | على شو | `notes.txt` (من) و `backup.txt` (لـ) |
| **الخيارات** | تعديل على طريقة الأمر، بتبلّش بـ `-` | متل `ls -l` (اعرض بالتفصيل) |

### وين أنا؟ المسار

نظام الملفات متل **شجرة**: بأولها **الجذر** `/`، وجواه مجلدات جواها مجلدات. وإنت دايماً «واقف» بمجلد واحد، اسمه **المجلد الحالي**.

| الرمز | يعني |
| --- | --- |
| `/` | الجذر: أول الشجرة (بويندوز `C:\`) |
| `~` | مجلدك الرئيسي (هون `/home/student`) |
| `.` | المجلد يلي أنا فيه |
| `..` | المجلد يلي فوقي (الأب) |

`rm` و `del` بيحذفوا **نهائياً**، بدون ما يمرّوا على سلة المحذوفات. اقرأ الأمر منيح قبل ما تكبس Enter.
</Aside>

## خطوات العملي

### 1. الطرفية التدريبية

<TerminalSim />

<Steps>

1. نفّذ المهمات بالترتيب. كل مهمة بتخلص بتصير خضرا ✔ لحالها.

2. بعد ما تفوت على `Documents`، جرّب `ls` و `ls -l`. **شو لازم تشوف:** `-l` بيعطيك تفاصيل: الصلاحيات، والمالك، والحجم.

3. لتعمل `notes.txt` فيه hello: `echo hello > notes.txt`. وجرّب `echo world >> notes.txt` وبعدين `cat notes.txt`. **شو لازم تشوف:** `>` بيكتب من جديد، و `>>` بيضيف على الآخر.

4. بعد ما تخلّص المهمات، اكتب `tree`. **شو لازم تشوف:** شجرة المجلدات يلي عملتها.

</Steps>

### 2. مسألة محلولة

**السؤال:** إنت بـ `/home/student`. شو بيطبع آخر أمر؟

```bash
cd Documents
mkdir os1
cd os1
cd ..
cd ../Pictures
pwd
```

**الحل خطوة بخطوة:**

| الأمر | وين صرت |
| --- | --- |
| `cd Documents` | `/home/student/Documents` |
| `mkdir os1` | ما تحركت (بس عملت مجلد) |
| `cd os1` | `/home/student/Documents/os1` |
| `cd ..` | `/home/student/Documents` |
| `cd ../Pictures` | `/home/student/Pictures` |

فالجواب: `/home/student/Pictures`. جرّبها بالطرفية التدريبية وتأكد.

### 3. تجربة حقيقية على ويندوز

<Steps>

1. افتح **Command Prompt**: اكتب `cmd` بقائمة ابدأ.

2. نفّذ هالأوامر سطر سطر:

   ```bat
   cd %USERPROFILE%\Desktop
   mkdir os1
   cd os1
   echo hello > notes.txt
   type notes.txt
   copy notes.txt backup.txt
   dir
   del backup.txt
   dir
   ```

3. افتح سطح المكتب بالماوس.

</Steps>

**شو لازم تشوف:** مجلد `os1` على سطح المكتب، وجواه `notes.txt` (يلي كتبته بالأوامر). و `backup.txt` بيظهر بأول `dir` وبيختفي بالتاني.

### 4. تجربة: العمليات الشغّالة

بـ Command Prompt اكتب:

```bat
tasklist
```

**شو لازم تشوف:** كل البرامج الشغّالة هلق، ولكل واحد رقم <Term t="PID" en="Process Identifier" def="رقم العملية: رقم مميز بيعطيه نظام التشغيل لكل برنامج شغّال، متل رقم الدور." /> والذاكرة يلي عم ياخدها. هي نفس القائمة يلي بمدير المهام، بس بالأوامر.

## النتيجة المتوقعة

- خلّصت المهمات التسعة بالطرفية التدريبية.
- عملت مجلد وملف حقيقيين على جهازك بالأوامر.
- بتعرف الأمر نفسه بلينكس وبويندوز.

## أخطاء شائعة

| الخطأ | الصح |
| --- | --- |
| `cd..` لاصقة | بلينكس لازم مسافة: `cd ..` |
| `cd documents` والمجلد اسمه `Documents` | لينكس بيفرّق بين الحروف الكبيرة والصغيرة |
| اسم فيه مسافة: `cd My Files` | حطه بين علامتي تنصيص: `cd "My Files"` |
| `rm` على مجلد | `rm` للملفات. للمجلد `rmdir` (إذا فاضي) أو `rm -r` |
| `>` بدل `>>` | `>` بيمسح القديم وبيكتب من جديد! |
| `ls` بويندوز | بويندوز `dir`، وبلينكس `ls` |

## الوظيفة

1. بالطرفية التدريبية: اعمل هالشجرة جوّا مجلدك الرئيسي، وصوّر نتيجة `tree`:
   - مجلد `university` جواه مجلدين: `os1` و `wireless`.
   - بكل واحد ملف `todo.txt` فيه سطر مكتوب بـ `echo`.
2. اكتب الأوامر بلينكس وبويندوز لـ: انسخ `a.txt` لـ `b.txt`، وبعدين احذف `a.txt`.
3. إنت بـ `/home/student/Documents/os1`. شو بيطبع `pwd` بعد `cd ../../Pictures`؟

## أسئلة المراجعة

<details class="answer">
<summary>شو الفرق بين الطرفية والصدفة؟</summary>

الطرفية هي الشاشة يلي بتكتب فيها. الصدفة هي البرنامج يلي بيفهم الأمر وبينفّذه.
</details>

<details class="answer">
<summary>شو بيعني <code>..</code> و <code>~</code>؟</summary>

`..` المجلد يلي فوق المجلد الحالي. `~` المجلد الرئيسي تبعك.
</details>

<details class="answer">
<summary>شو الفرق بين <code>&gt;</code> و <code>&gt;&gt;</code>؟</summary>

`>` بيكتب الملف من جديد (بيمسح القديم). `>>` بيضيف على آخر الملف.
</details>

<details class="answer">
<summary>شو يقابل <code>ls</code> و <code>cat</code> و <code>rm</code> بويندوز؟</summary>

`dir` و `type` و `del`.
</details>

<details class="answer">
<summary>ليش الخوادم بتنداروا بالأوامر؟</summary>

لأنه أغلبها ما إلها شاشة، وبتنداروا عن بعد عبر الشبكة، والأوامر أسرع ومنقدر نأتمتها.
</details>
