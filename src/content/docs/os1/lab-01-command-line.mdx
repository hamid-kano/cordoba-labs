<Aside type="tip" title="الفكرة ببساطة">
بالمطعم فيك **تأشّر** على صورة الأكلة بالمنيو، أو **تقول** للجرسون بالضبط شو بدك: «شاورما بدون توم وزيادة مخلل». التأشير أسهل بالأول، بس الحكي أسرع وأدق. نفس الشي مع الكمبيوتر: يا بتكبس بالماوس على الأيقونات، يا بتكتب **أوامر**. وكتير شغلات بويندوز (متل حل مشاكل الشبكة) أسرع بكتير بالأوامر.
</Aside>

## أهداف الجلسة

- تعرف شو هو سطر الأوامر وليش لسا منستخدمه.
- تتنقّل بين المجلدات بـ **Command Prompt** وتعرف وين إنت.
- تعمل ملفات ومجلدات، وتنسخ، وتنقل، وتحذف بالأوامر.
- تشوف البرامج الشغّالة بالأوامر.

## المتطلبات

- المتصفح بس للطرفية التدريبية.
- لابتوب ويندوز للتجربة الحقيقية (أو اعملها مع رفيقك).

## ملخص نظري

<Concept term="سطر الأوامر" en="Command Line Interface">

طريقة للتعامل مع نظام التشغيل بـ**كتابة أوامر** بدل الكبس بالماوس على الأيقونات. الشاشة السودا يلي بتكتب فيها اسمها <Term t="الطرفية" en="Terminal" def="الشاشة أو البرنامج يلي بتكتب فيه الأوامر. بويندوز اسمها Command Prompt أو PowerShell." />، والبرنامج يلي بيفهم أوامرك وبينفّذها اسمه <Term t="الصدفة" en="Shell" def="البرنامج يلي بيقرأ الأمر يلي كتبته، وبيطلب من نظام التشغيل ينفّذه، وبيعرضلك النتيجة. بويندوز هو cmd أو PowerShell." />.

بويندوز في اتنين: **Command Prompt** (اسمه `cmd`، القديم والبسيط، ورح نشتغل عليه) و **PowerShell** (الأحدث والأقوى).

**ليش لسا منستخدمه؟**
- **أسرع:** أمر واحد بيعمل شغل عشرات الكبسات.
- **حل المشاكل:** أوامر متل `ipconfig` و `ping` (جرّبتها بمادة الشبكات) ما إلها بديل سهل بالماوس.
- **الأتمتة:** بتكتب الأوامر بملف `.bat`، وبتشغّلها لحالها (متل نسخة احتياطية كل ليلة).

</Concept>

### شكل الأمر

```bat
copy  notes.txt  backup.txt
```

| الجزء | يعني | هون |
| --- | --- | --- |
| **الأمر** | شو بدك تعمل | `copy` (انسخ) |
| **المعاملات** | على شو | `notes.txt` (من) و `backup.txt` (لـ) |
| **الخيارات** | تعديل على طريقة الأمر، بتبلّش بـ `/` | متل `tree /f` (اعرض الملفات كمان) |

### وين أنا؟ المسار

الملفات مرتبة متل **شجرة**: بأولها القرص `C:\`، وجواه مجلدات جواها مجلدات. وإنت دايماً «واقف» بمجلد واحد، اسمه **المجلد الحالي**، ومكتوب قبل علامة `>`:

```text
C:\Users\student>
```

| الرمز | يعني |
| --- | --- |
| `C:\` | أول القرص |
| `.` | المجلد يلي أنا فيه |
| `..` | المجلد يلي فوقي (الأب) |
| `%USERPROFILE%` | مجلدك الرئيسي (متل `C:\Users\student`) |

### أهم الأوامر

| بدي... | الأمر | مثال |
| --- | --- | --- |
| أعرف وين أنا | `cd` لحاله | `cd` |
| أشوف شو في | `dir` | `dir` |
| أفوت على مجلد | `cd` | `cd Documents` و `cd ..` و `cd \` |
| أعمل مجلد | `mkdir` | `mkdir os1` |
| أكتب بملف | `echo ... >` | `echo hello > notes.txt` |
| أضيف على ملف | `echo ... >>` | `echo world >> notes.txt` |
| أعرض محتوى ملف | `type` | `type notes.txt` |
| أنسخ | `copy` | `copy notes.txt backup.txt` |
| أنقل | `move` | `move notes.txt ..` |
| أغيّر الاسم | `ren` | `ren backup.txt old.txt` |
| أحذف ملف | `del` | `del old.txt` |
| أحذف مجلد | `rmdir` | `rmdir empty` (و `rmdir /s` إذا فيه شي) |
| أشوف الشجرة | `tree` | `tree /f` |
| أنظّف الشاشة | `cls` | `cls` |
| أنسخ مجلد كامل | `xcopy` | `xcopy Documents Backup /e /i` |
| أخبّي ملف أو أحميه | `attrib` | `attrib +h notes.txt` و `attrib +r notes.txt` |
| أدوّر على كلمة بملف | `find` | `find "hello" notes.txt` |
| أقارن ملفين | `fc` | `fc a.txt b.txt` |

### أوامر للنظام والشبكة

| بدي... | الأمر | مثال |
| --- | --- | --- |
| أشوف البرامج الشغّالة | `tasklist` | `tasklist` |
| أسكّر برنامج معلّق | `taskkill` | `taskkill /im notepad.exe` |
| أعرف عنوان <Term t="IP" en="Internet Protocol" def="بروتوكول الإنترنت: يعطي كل جهاز عنواناً، ويوصل الرسالة إلى الجهاز الصحيح." /> تبعي | `ipconfig` | `ipconfig` و `ipconfig /all` |
| أجرّب الاتصال بجهاز | `ping` | `ping google.com` |
| أعرف معلومات جهازي | `systeminfo` | `systeminfo` |
| أشوف متغيرات النظام | `set` و `echo %...%` | `echo %USERNAME%` |

<Aside type="tip" title="الأنبوب «|»: فلتر للنتيجة">
لما تكون النتيجة طويلة، فيك تمرّرها لـ `find` لتطلع بس الأسطر يلي فيها كلمة معينة. مثلاً `tasklist | find "chrome"` بيطلّع بس برامج كروم.
</Aside>

<Aside type="caution" title="ما في سلة محذوفات!">
`del` و `rmdir /s` بيحذفوا **نهائياً**، بدون ما يمرّوا على سلة المحذوفات. اقرأ الأمر منيح قبل ما تكبس Enter.
</Aside>

## خطوات العملي

### 1. الطرفية التدريبية

<WinTerminalSim />

<TabItem label="Linux (اختياري)">

نفس المهمات بس بأوامر لينكس، لأنه أغلب **الخوادم** بالعالم لينكس. الفرق الأساسي: `ls` بدل `dir`، و `cat` بدل `type`، و `cp` بدل `copy`، و `rm` بدل `del`، و `pwd` لتعرف وين إنت، والمسار بـ `/` بدل `\`.

<TerminalSim />

</TabItem>
</Tabs>

<Steps>

1. نفّذ مهمات طرفية ويندوز بالترتيب. كل مهمة بتخلص بتصير خضرا ✔ لحالها.

2. بعد ما تفوت على `Documents`، جرّب `dir`. **شو لازم تشوف:** المجلدات مكتوب جنبها `<DIR>`، والملفات جنبها حجمها بالبايت.

3. لتعمل `notes.txt` فيه hello: `echo hello > notes.txt`. وجرّب `echo world >> notes.txt` وبعدين `type notes.txt`. **شو لازم تشوف:** `>` بيكتب من جديد، و `>>` بيضيف على الآخر.

4. بعد ما تخلّص المهمات، اكتب `tree /f`. **شو لازم تشوف:** شجرة المجلدات والملفات يلي عملتها.

5. جرّب تكتب `ls` (أمر لينكس). **شو لازم تشوف:** الطرفية بتقلك شو يقابله بويندوز.

6. اكبس على **«2. النظام والشبكة»** فوق المهمات، ونفّذها. **شو لازم تشوف:** بعد `taskkill`، برنامج `notepad.exe` بيختفي من `tasklist`. وبعد `attrib +h`، الملف ما بيبيّن بـ `dir`، بس بيبيّن بـ `dir /a`.

</Steps>

### 2. مسألة محلولة

**السؤال:** إنت بـ `C:\Users\student`. شو بيطبع آخر أمر؟

```bat
cd Documents
mkdir os1
cd os1
cd ..
cd ..\Pictures
cd
```

**الحل خطوة بخطوة:**

| الأمر | وين صرت |
| --- | --- |
| `cd Documents` | `C:\Users\student\Documents` |
| `mkdir os1` | ما تحركت (بس عملت مجلد) |
| `cd os1` | `C:\Users\student\Documents\os1` |
| `cd ..` | `C:\Users\student\Documents` |
| `cd ..\Pictures` | `C:\Users\student\Pictures` |

فالجواب: `C:\Users\student\Pictures`. جرّبها بالطرفية التدريبية وتأكد.

### 3. تجربة حقيقية على جهازك

<Steps>

1. افتح **Command Prompt**: اكتب `cmd` بقائمة ابدأ.

2. نفّذ هالأوامر سطر سطر:

   ```bat
   cd %USERPROFILE%\Desktop
   mkdir os1
   cd os1
   echo hello > notes.txt
   type notes.txt
   copy notes.txt backup.txt
   dir
   del backup.txt
   dir
   ```

3. افتح سطح المكتب بالماوس.

</Steps>

**شو لازم تشوف:** مجلد `os1` على سطح المكتب، وجواه `notes.txt` (يلي كتبته بالأوامر). و `backup.txt` بيظهر بأول `dir` وبيختفي بالتاني.

### 4. تجربة: البرامج الشغّالة

بـ Command Prompt اكتب:

```bat
tasklist
```

**شو لازم تشوف:** كل البرامج الشغّالة هلق، ولكل واحد رقم <Term t="PID" en="Process Identifier" def="رقم العملية: رقم مميز بيعطيه نظام التشغيل لكل برنامج شغّال، متل رقم الدور." /> والذاكرة يلي عم ياخدها. هي نفس القائمة يلي بمدير المهام، بس بالأوامر.

## النتيجة المتوقعة

- خلّصت مجموعتي المهمات بطرفية ويندوز التدريبية (الملفات، والنظام والشبكة).
- عملت مجلد وملف حقيقيين على جهازك بالأوامر.
- بتعرف تتنقّل بين المجلدات وتعرف وين إنت.

## أخطاء شائعة

| الخطأ | الصح |
| --- | --- |
| `ls` بويندوز | بويندوز `dir` (و `ls` للينكس) |
| اسم فيه مسافة: `cd My Files` | حطه بين علامتي تنصيص: `cd "My Files"` |
| `del` على مجلد | `del` للملفات. للمجلد `rmdir` |
| `rmdir` على مجلد فيه ملفات | `rmdir /s` (وانتبه، بيحذف كل شي جواه) |
| `>` بدل `>>` | `>` بيمسح القديم وبيكتب من جديد! |
| `/` بالمسار | ويندوز بيستخدم `\` (متل `cd ..\Pictures`) |

## الوظيفة

1. بالطرفية التدريبية: اعمل هالشجرة جوّا مجلدك الرئيسي، وصوّر نتيجة `tree /f`:
   - مجلد `university` جواه مجلدين: `os1` و `wireless`.
   - بكل واحد ملف `todo.txt` فيه سطر مكتوب بـ `echo`.
2. اكتب الأوامر لـ: انسخ `a.txt` لـ `b.txt`، وبعدين غيّر اسم `b.txt` لـ `c.txt`، وبعدين احذف `a.txt`.
3. إنت بـ `C:\Users\student\Documents\os1`. شو بيطبع `cd` بعد `cd ..\..\Pictures`؟
4. على جهازك الحقيقي: اكتب `ipconfig` وسجّل عنوان IP والـ Default Gateway، وبعدين اعمل `ping` للـ Gateway. نجح؟
5. اكتب الأمر يلي بيطلّع بس سطر `explorer.exe` من قائمة البرامج الشغّالة.

## أسئلة المراجعة

<details class="answer">
<summary>شو الفرق بين الطرفية والصدفة؟</summary>

الطرفية هي الشاشة يلي بتكتب فيها. الصدفة هي البرنامج يلي بيفهم الأمر وبينفّذه (متل `cmd`).
</details>

<details class="answer">
<summary>شو بيعني <code>..</code> بالمسار؟</summary>

المجلد يلي فوق المجلد الحالي.
</details>

<details class="answer">
<summary>شو الفرق بين <code>&gt;</code> و <code>&gt;&gt;</code>؟</summary>

`>` بيكتب الملف من جديد (بيمسح القديم). `>>` بيضيف على آخر الملف.
</details>

<details class="answer">
<summary>كيف بتعرف وين إنت بـ cmd؟</summary>

مكتوب قبل علامة `>` بأول السطر، أو بتكتب `cd` لحاله.
</details>

<details class="answer">
<summary>شو بيعمل <code>tasklist</code>؟</summary>

بيعرض كل البرامج الشغّالة على الجهاز، ولكل واحد رقم العملية والذاكرة يلي عم ياخدها.
</details>

<details class="answer">
<summary>برنامج معلّق وما عم يتسكّر. شو بتكتب؟</summary>

`taskkill /im اسم_البرنامج.exe`، أو بالرقم: `taskkill /pid الرقم`. وإذا ما رضي، بتضيف `/f` لتجبره.
</details>

<details class="answer">
<summary>شو الفرق بين <code>copy</code> و <code>xcopy</code>؟</summary>

`copy` بينسخ ملفات. `xcopy` بينسخ مجلد كامل مع المجلدات يلي جواه (بـ `/e`)، فبينفع للنسخ الاحتياطي.
</details>
