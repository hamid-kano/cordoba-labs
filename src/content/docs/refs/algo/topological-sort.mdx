<Aside type="tip" title="الفكرة ببساطة">
عندما تلبس في الصباح: الجوارب قبل الحذاء، والقميص قبل السترة، والبنطال قبل الحزام. لكن لا يهم هل تلبس الساعة قبل القميص أم بعده. عندك **قيود** («هذا قبل ذاك»)، وتريد ترتيباً **يحترمها كلها**. وإذا كان في القيود تناقض («الحذاء قبل الجوارب، والجوارب قبل الحذاء»)، فلا يوجد ترتيب ممكن أبداً. هذا هو **الترتيب الطوبولوجي**.
</Aside>

## ماذا ستتعلم؟

- ما هو **الرسم الموجّه بلا حلقات**، ولماذا هو المكان الطبيعي للمتطلبات.
- ما هو **الترتيب الطوبولوجي**، ولماذا قد يوجد أكثر من ترتيب صحيح.
- خوارزمية **Kahn**: عدّ المتطلبات الباقية.
- الترتيب **بالبحث بالعمق**: آخر من ينتهي، أول من يُكتب.
- كيف نكتشف **الحلقة** التي تجعل الترتيب مستحيلاً.

## المتطلبات رسم موجّه

نمثّل كل مهمة (أو مقرر) بعقدة، وكل قيد «أ قبل ب» **بسهم** من أ إلى ب. فنحصل على رسم موجّه. وإذا لم يكن فيه أي حلقة، نسمّيه <Term t="DAG" en="Directed Acyclic Graph" def="رسم موجّه لا توجد فيه أي حلقة: لا يمكن أن تبدأ من عقدة وتتبع الأسهم فتعود إليها." />، أي رسماً موجّهاً بلا حلقات.

<Concept term="الترتيب الطوبولوجي" en="Topological Sort">

ترتيب لعقد رسم موجّه بلا حلقات، بحيث يأتي **كل سهم من عقدة سابقة إلى عقدة لاحقة**. أي أن كل مهمة تأتي بعد كل ما تحتاجه. مثل خطة دراسية تحترم كل المتطلبات.

**لماذا نستخدمه؟** لأن مسائل كثيرة فيها «هذا يجب أن يحدث قبل ذاك»، ونريد ترتيباً لتنفيذها، أو نريد أن نعرف أن القيود متناقضة.

**أين يُستخدم؟** في أدوات بناء البرامج (أي ملف يُترجم أولاً)، ومديري الحزم مثل <Term t="npm" en="Node Package Manager" def="مدير حزم لغة JavaScript، يثبّت المكتبات التي يحتاجها المشروع والمكتبات التي تحتاجها هي." /> و `pip` (أي مكتبة تُثبّت أولاً)، وجداول بيانات Excel (أي خلية تُحسب أولاً)، وخطط المشاريع (المهام والمسار الحرج)، والخطط الدراسية.

</Concept>

## رتّب بنفسك

<TopoLab />

**ماذا يجب أن ترى؟**

1. **أنا أرتّب:** في البداية «برمجة 1» و«رياضيات 1» فقط بنفسجيان (جاهزان). اضغط «الخوارزميات» مباشرة: ترفض الأداة وتقول لك ما ينقصك.
2. أكمل الخطة: كل مقرر تأخذه يفتح مقررات جديدة. وجرّب مرة ثانية بترتيب مختلف: **يوجد أكثر من خطة صحيحة**.
3. **خوارزمية Kahn:** الرقم فوق كل مقرر هو عدد متطلباته الباقية. كل مقرر يصل إلى 0 يدخل الطابور.
4. فعّل **«أضف متطلباً دائرياً»**: الآن «برمجة 2» تحتاج «الذكاء الصنعي»، الذي يحتاج «الخوارزميات»، التي تحتاج «بنى المعطيات»، التي تحتاج «برمجة 2»! حاول أن ترتّب، ثم شغّل Kahn: يتوقف بعد 3 مقررات.

## خوارزمية Kahn

الفكرة: ما ليس له متطلبات يمكن أن نبدأ به. وعندما ننتهي منه، نشطبه من متطلبات غيره، فقد يصبح غيره جاهزاً.

1. احسب لكل عقدة <Term t="درجة الدخول" en="In-degree" def="عدد الأسهم الداخلة إلى العقدة في رسم موجّه، أي عدد متطلباتها." /> (عدد الأسهم الداخلة إليها).
2. ضع في طابور كل العقد ذات الدرجة 0.
3. ما دام الطابور غير فارغ: أخرج عقدة، وأضفها إلى الترتيب، وأنقص 1 من كل عقدة تشير إليها. ما يصل إلى 0 يدخل الطابور.
4. إذا انتهينا وبقيت عقد لم تدخل الترتيب، ففي الرسم **حلقة**.

<Tabs syncKey="algo-lang">
<TabItem label="Python">

```python
from collections import deque

def kahn(nodes, edges):               # edges: (before, after)
    indeg = {v: 0 for v in nodes}
    out = {v: [] for v in nodes}
    for a, b in edges:
        out[a].append(b)
        indeg[b] += 1
    q = deque(v for v in nodes if indeg[v] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in out[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    if len(order) < len(nodes):
        raise ValueError("cycle! no valid order")
    return order

print(kahn(["socks", "shoes", "shirt", "jacket"],
           [("socks", "shoes"), ("shirt", "jacket")]))
```

</TabItem>
<TabItem label="C++">

```cpp
vector<int> kahn(int n, const vector<pair<int,int>>& edges) {
    vector<int> indeg(n, 0), order;
    vector<vector<int>> out(n);
    for (auto [a, b] : edges) { out[a].push_back(b); indeg[b]++; }
    queue<int> q;
    for (int v = 0; v < n; v++) if (indeg[v] == 0) q.push(v);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (int v : out[u])
            if (--indeg[v] == 0) q.push(v);
    }
    if ((int)order.size() < n) order.clear();   // cycle: no valid order
    return order;
}
```

</TabItem>
</Tabs>

**التعقيد:** $O(V + E)$: كل عقدة تدخل الطابور مرة، وكل سهم يُنقص مرة.

## بالبحث بالعمق

طريقة ثانية جميلة: نبحث بالعمق، وعندما **ننتهي** من عقدة (زرنا كل ما بعدها)، نضعها في **بداية** القائمة. فالعقدة التي ننتهي منها آخراً هي أول من يُكتب. لماذا يعمل؟ لأننا لا ننتهي من عقدة إلا بعد أن ننتهي من كل ما يعتمد عليها، فكلها تكون بعدها في القائمة.

<Tabs syncKey="algo-lang">
<TabItem label="Python">

```python
def topo_dfs(graph):                   # graph[u] = list of things after u
    WHITE, GRAY, BLACK = 0, 1, 2       # not seen, on the current path, finished
    color = {u: WHITE for u in graph}
    order = []

    def visit(u):
        color[u] = GRAY
        for v in graph[u]:
            if color[v] == GRAY:
                raise ValueError("cycle!")   # back to the current path
            if color[v] == WHITE:
                visit(v)
        color[u] = BLACK
        order.append(u)                # finished: goes after its successors

    for u in graph:
        if color[u] == WHITE:
            visit(u)
    return order[::-1]                 # reverse finishing order
```

vector<vector<int>> g;
vector<int> color, order;              // 0 white, 1 gray, 2 black
bool hasCycle = false;

void visit(int u) {
    color[u] = 1;
    for (int v : g[u]) {
        if (color[v] == 1) hasCycle = true;    // back edge
        else if (color[v] == 0) visit(v);
    }
    color[u] = 2;
    order.push_back(u);
}

والألوان الثلاثة هي الطريقة المعتادة لاكتشاف الحلقة: **الرمادي** يعني «في الطريق الحالي، لم ننتهِ منه». فإذا وصلنا إلى عقدة رمادية، فقد عدنا إلى الطريق نفسه: حلقة.

| | **Kahn** | **البحث بالعمق** |
| --- | --- | --- |
| الفكرة | ابدأ بما ليس له متطلبات | عكس ترتيب الانتهاء |
| البنية | طابور ودرجات الدخول | العودية (مكدس) |
| اكتشاف الحلقة | بقيت عقد خارج الترتيب | وصلنا إلى عقدة رمادية |
| الزمن | $O(V + E)$ | $O(V + E)$ |
| ميزة | يعطي «من الجاهز الآن؟» في كل لحظة، فيناسب التنفيذ المتوازي | قصير جداً في الكود |

## الخلاصة

- **الرسم الموجّه بلا حلقات** يمثّل المتطلبات: سهم من أ إلى ب يعني «أ قبل ب».
- **الترتيب الطوبولوجي**: ترتيب تأتي فيه كل عقدة بعد كل ما يشير إليها. قد يوجد أكثر من ترتيب.
- **Kahn**: ابدأ بدرجة الدخول 0، وأنقص الدرجات، وكل ما يصل إلى 0 يصبح جاهزاً.
- **بالبحث بالعمق**: عكس ترتيب الانتهاء، والعقدة الرمادية تكشف الحلقة.
- إذا كان في الرسم **حلقة**، فلا يوجد أي ترتيب، والخوارزميتان تكتشفان ذلك. والزمن $O(V + E)$.

## أسئلة المراجعة

<details class="answer">
<summary>اكتب خطوات Kahn على خطة المقررات: ما المقررات في الطابور في البداية؟</summary>

«برمجة 1» و«رياضيات 1»، لأن درجة دخولهما 0. بعد أخذ «برمجة 1» تصبح درجة «برمجة 2» صفراً فتدخل الطابور، وبعد «رياضيات 1» تدخل «رياضيات متقطعة».
</details>

<details class="answer">
<summary>لماذا لا يوجد ترتيب طوبولوجي لرسم فيه حلقة؟</summary>

لأن كل عقدة في الحلقة يجب أن تأتي بعد العقدة التي قبلها في الحلقة. فإذا تتبعنا الحلقة كاملة، نصل إلى أن العقدة يجب أن تأتي بعد نفسها، وهذا مستحيل.
</details>

<details class="answer">
<summary>كيف تعرف أقل عدد من الفصول الدراسية لإنهاء كل المقررات، إذا كان يمكن دراسة أي عدد من المقررات الجاهزة في الفصل الواحد؟</summary>

نطبّق Kahn طبقة طبقة: الفصل الأول كل المقررات ذات الدرجة 0، والفصل الثاني كل ما أصبح جاهزاً بعدها، وهكذا. وعدد الطبقات هو أقل عدد من الفصول، ويساوي طول أطول سلسلة متطلبات.
</details>

<details class="answer">
<summary>في البحث بالعمق، ما الفرق بين الوصول إلى عقدة رمادية والوصول إلى عقدة سوداء؟</summary>

الرمادية ما زالت في الطريق الحالي، فالوصول إليها يعني أننا عدنا إلى طريقنا: حلقة. أما السوداء فقد انتهينا منها في طريق سابق، فالوصول إليها طبيعي ولا يعني حلقة.
</details>
