## ماذا ستتعلم؟

- ما هي الخوارزمية، ومن أين جاء اسمها.
- الخصائص الخمس لأي خوارزمية صحيحة.
- أربع طرق لكتابة الخوارزمية: باللغة، وبالمخطط الانسيابي، وبشبه الكود، وبلغة برمجة.
- كيف **تتتبّع** خوارزمية بجدول، خطوة خطوة.
- متى تكون الخوارزمية **صحيحة**، ومتى تكون **جيدة**.

## من الخوارزمي إلى الحاسوب

في بغداد، قبل أكثر من ألف ومئتي عام، كتب العالم **محمد بن موسى الخوارزمي** كتاباً يشرح فيه طرقاً منظّمة للحساب خطوة خطوة. وعندما تُرجم كتابه إلى اللاتينية، صار اسمه يُكتب «Algoritmi»، ومنه جاءت كلمة <Term t="Algorithm" en="Algorithm" def="الكلمة الإنكليزية للخوارزمية، وأصلها اسم العالم محمد بن موسى الخوارزمي." /> التي يستخدمها العالم كله اليوم. ومن كتابه الآخر جاءت كلمة «الجبر» أيضاً.

<Concept term="الخوارزمية" en="Algorithm">

**مجموعة خطوات واضحة ومرتّبة ومحدودة، تأخذ مدخلات وتحوّلها إلى المخرجات المطلوبة.** مثل وصفة الطبخ: المكونات هي المدخلات، والخطوات هي الخوارزمية، والطبق هو المخرج.

**لماذا نستخدمها؟** لأن الحاسوب لا يفكر. هو سريع جداً، لكنه يحتاج من يخبره **بالضبط** ماذا يفعل. والخوارزمية هي «الفكرة» قبل أن تصبح كوداً: إذا كانت الفكرة خاطئة، فلن ينقذها أي كود.

**أين تُستخدم؟** في كل مكان: الخرائط تجد لك أقصر طريق، ومحرك البحث يرتّب لك ملايين الصفحات في جزء من الثانية، والهاتف يضغط صورك، والتطبيق يقترح عليك فيديو. كل ذلك خوارزميات.

</Concept>

## أربع طرق لكتابة الخوارزمية

الفكرة نفسها يمكن أن تُكتب بطرق كثيرة. ولنأخذ مثالاً: **أكبر عدد في قائمة**.

### 1. باللغة العادية

«انظر إلى أول عدد، واعتبره الأكبر. ثم مُرّ على باقي الأعداد واحداً واحداً: إذا وجدت عدداً أكبر من الذي معك، احفظه بدلاً منه. في النهاية، العدد الذي معك هو الأكبر.»

سهلة للقراءة، لكنها قد تكون غير دقيقة في الخوارزميات الطويلة.

### 2. بالمخطط الانسيابي

رسم بأشكال متفق عليها. وتُسمّى <Term t="المخطط الانسيابي" en="Flowchart" def="رسم يصف الخوارزمية بأشكال متفق عليها: شكل بيضاوي للبداية والنهاية، ومستطيل للعملية، ومعيّن للقرار، ومتوازي أضلاع للإدخال والإخراج." />:

| الشكل | المعنى |
| --- | --- |
| شكل بيضاوي | البداية أو النهاية |
| متوازي أضلاع | إدخال أو إخراج |
| مستطيل | عملية حسابية أو تخزين قيمة |
| معيّن | قرار: سؤال جوابه نعم أو لا |
| سهم | اتجاه السير |

هذا مخطط لخوارزمية **مجموع الأعداد من 1 إلى n**. نفّذه خطوة خطوة، وراقب **جدول التتبع**:

<FlowRunner />

**ماذا يجب أن ترى؟** مع n = 4، يدور السهم في الحلقة أربع مرات، والمجموع يصبح 1، ثم 3، ثم 6، ثم 10. وعندما يصبح i = 5، يكون جواب السؤال «لا»، فنخرج ونطبع 10.

<Aside type="note" title="جدول التتبع">
هذا الجدول اسمه <Term t="جدول التتبع" en="Trace Table" def="جدول نكتب فيه قيم المتغيرات بعد كل خطوة من الخوارزمية، لنفهم ما يحدث ونكتشف الأخطاء." />، وهو أقوى أداة لفهم أي خوارزمية: نكتب قيمة كل متغير بعد كل خطوة. استخدمه بالورقة والقلم في الامتحان، وعندما لا تفهم لماذا يعطي برنامجك نتيجة غريبة.
</Aside>

### 3. بشبه الكود

لغة بين العربية والبرمجة، اسمها <Term t="شبه الكود" en="Pseudocode" def="طريقة لكتابة الخوارزمية تشبه لغات البرمجة، لكن دون الالتزام بقواعد لغة معيّنة، فيفهمها أي مبرمج." />. لا يفهمها الحاسوب، لكن يفهمها أي مبرمج مهما كانت لغته:

```text
MAX(A):
    best ← A[0]
    for i ← 1 to length(A) − 1:
        if A[i] > best:
            best ← A[i]
    return best
```

### 4. بلغة برمجة

وهي الشكل الذي ينفّذه الحاسوب فعلاً. في هذا المرجع نكتب كل خوارزمية بلغتين: <Term t="Python" en="Python" def="لغة برمجة سهلة القراءة، قريبة جداً من شبه الكود." /> لأنها الأقرب إلى شبه الكود، و <Term t="C++" en="C Plus Plus" def="لغة برمجة سريعة جداً، وهي الأشهر في مسابقات البرمجة وفي الأنظمة التي تحتاج سرعة عالية." /> لأنها الأشهر في المسابقات. اختر اللغة مرة واحدة، وسيتذكرها الموقع في كل الصفحات:

<Tabs syncKey="algo-lang">
<TabItem label="Python">

```python
def find_max(a):
    best = a[0]
    for x in a[1:]:
        if x > best:
            best = x
    return best

print(find_max([3, 8, 2, 9, 4]))  # 9
```

</TabItem>
<TabItem label="C++">

```cpp
#include <iostream>
#include <vector>
using namespace std;

int findMax(const vector<int>& a) {
    int best = a[0];
    for (size_t i = 1; i < a.size(); i++)
        if (a[i] > best) best = a[i];
    return best;
}

int main() {
    cout << findMax({3, 8, 2, 9, 4});  // 9
}
```

</TabItem>

## الخوارزمية والبرنامج

| | **الخوارزمية** | **البرنامج** |
| --- | --- | --- |
| ما هي؟ | الفكرة والخطوات | الفكرة مكتوبة بلغة برمجة |
| بأي لغة؟ | أي لغة، حتى العربية | لغة برمجة محددة |
| من ينفّذها؟ | إنسان أو حاسوب | الحاسوب |
| مثال | وصفة الكعكة | الكعكة نفسها في الفرن |

خوارزمية واحدة يمكن أن تصبح مئات البرامج بلغات مختلفة. لذلك **نتعلم الخوارزميات مرة واحدة، ونستخدمها في كل اللغات**.

## أقدم خوارزمية مكتوبة

قبل الخوارزمي بألف عام تقريباً، كتب العالم اليوناني **إقليدس** طريقة لإيجاد <Term t="القاسم المشترك الأكبر" en="Greatest Common Divisor (GCD)" def="أكبر عدد يقسم عددين دون باقٍ. مثلاً القاسم المشترك الأكبر للعددين 12 و 18 هو 6." /> لعددين، وما زلنا نستخدمها حتى اليوم في تشفير الإنترنت. فكرتها بسيطة:

> اقسم الكبير على الصغير، وخذ الباقي. ثم كرّر مع الصغير والباقي، حتى يصبح الباقي صفراً. آخر عدد قسمت عليه هو الجواب.

وللفكرة صورة جميلة: مستطيل طوله a وعرضه b، نقصّ منه أكبر مربعات ممكنة، ثم نكرر مع ما تبقى. ضلع آخر مربع هو الجواب:

<EuclidLab />

**ماذا يجب أن ترى؟** مع 48 و 18: مربعان ضلعهما 18، ثم مربع ضلعه 12، ثم مربعان ضلعهما 6 يملآن الباقي تماماً. فالجواب **6**، بثلاث خطوات فقط. جرّب 1071 و 462 (من كتاب إقليدس نفسه)، وجرّب عددين متتاليين مثل 55 و 34.

<Tabs syncKey="algo-lang">
<TabItem label="Python">

```python
def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a

print(gcd(48, 18))  # 6
```

</TabItem>
<TabItem label="C++">

```cpp
int gcd(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}
// gcd(48, 18) == 6
```

</TabItem>
</Tabs>

## متى تكون الخوارزمية جيدة؟

الخوارزمية الجيدة يجب أن تكون:

1. **صحيحة:** تعطي الجواب الصحيح لكل المدخلات المسموحة، لا لبعضها فقط.
2. **فعّالة:** لا تضيّع الوقت ولا الذاكرة. وهذا موضوع [الصفحة التالية](../complexity/).
3. **واضحة:** يستطيع غيرك أن يفهمها ويتأكد من صحتها.

ولكي تتأكد من الصحة، جرّب دائماً <Term t="الحالات الحدّية" en="Edge Cases" def="المدخلات الغريبة أو المتطرفة التي ينساها المبرمج غالباً، مثل القائمة الفارغة، أو عنصر واحد، أو أرقام سالبة، أو أعداد كبيرة جداً." />: ماذا لو كانت القائمة فارغة؟ فيها عنصر واحد؟ كل الأعداد سالبة؟ كل الأعداد متساوية؟

## الخلاصة

- **الخوارزمية** خطوات واضحة ومرتبة ومحدودة، تحوّل المدخلات إلى مخرجات. واسمها من العالم **الخوارزمي**.
- لها **خمس خصائص**: مدخلات، ومخرجات، ووضوح، ومحدودية، وفعالية.
- تُكتب **باللغة**، أو **بالمخطط الانسيابي**، أو **بشبه الكود**، أو **بلغة برمجة**.
- **جدول التتبع** يبيّن قيمة كل متغير بعد كل خطوة، وهو أقوى أداة لفهم الخوارزمية.
- الخوارزمية الجيدة **صحيحة** لكل المدخلات (جرّب الحالات الحدّية)، و**فعّالة**، و**واضحة**.

<summary>احسب القاسم المشترك الأكبر للعددين 1071 و 462 بخوارزمية إقليدس.</summary>

1071 = 2 × 462 + 147، ثم 462 = 3 × 147 + 21، ثم 147 = 7 × 21 + 0. الباقي صفر، فالجواب 21.
</details>

<details class="answer">
<summary>هل «امشِ حتى تجد صيدلية» خوارزمية صحيحة؟ لماذا؟</summary>

ليست كاملة: إذا لم توجد صيدلية في الطريق، لن تنتهي أبداً (مخالفة للمحدودية). الأصح: «امشِ حتى تجد صيدلية، أو حتى نهاية الشارع».
</details>

<details class="answer">
<summary>لماذا نتعلم الخوارزميات إذا كانت لغات البرمجة تتغيّر؟</summary>

لأن الخوارزمية فكرة لا تتعلق بلغة. خوارزمية إقليدس عمرها أكثر من ألفي عام، وما زالت تعمل في كل لغة. اللغات تتغيّر، والأفكار تبقى.
</details>
